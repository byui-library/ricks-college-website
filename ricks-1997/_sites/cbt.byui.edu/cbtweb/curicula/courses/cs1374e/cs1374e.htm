Cisco BCRAN: Configuring ISDN and DDR to Enhance Remote Connectivity

General Information

Course Duration:
 4 hours

Audience:
Network administrators, network specialists, and technicians, who configure and support remote access networks

Prerequisites:
A knowledge of the Cisco IOS 11.3: ICRC curriculum; all preceding courses in the Cisco BCRAN curriculum

Topics Covered

  • ISDN features
  • ISDN network components
  • ISDN operation
  • DDR operation
  • Configuring ISDN for DDR
  • DDR configuration tasks
  • DDR configurations
  • B-channel aggregation
  • Caller ID screening
  • PRI configuration tasks
  • BRI configuration on branch routers
  • PRI configuration on central routers
  • Verifying ISDN links

Course Aim

To introduce the features and concepts of ISDN, explain the configuration of integrated services digital network (ISDN) basic rate interface (BRI) and primary rate interface (PRI), and describe dial-on-demand routing configuration on an ISDN connection


Learning Objectives

After taking this course, the user should be able to
  • discuss the differences between ISDN and asynchronous communications

  • describe BRI and PRI services and the channel configurations for T1 and E1 PRI

  • list the groupings and reference points for BRI and PRI

  • identify the layer 1-to-3 protocols for the D and B channels

  • describe call setup and call teardown

  • explain dial-on-demand operation

  • configure BRI, PRI, and dial on demand on BRI and PRI

  • discuss the use of Multilink PPP and bandwidth on demand and show how they are configured for ISDN

  • explain the implementation of Caller ID screening and rate adaptation

  • configure and verify communications between two routers using BRI and PRI


Course Incorporates: Test, hands-on exercises
