Logging into the CBT System

Any user logging into the Ricks College CBT courses must do so using his or her personal username and password. However, if using Netscape Navigator, the system requires a domain designation to preceed the username. For example, if my username were "username", and I am a student using the "student" domain, then I would log into the CBT system as:

Username: student\username

Password: regular network password

If using Internet Explorer I would enter the domain in the domain text box:

Username: username

Password: regular network password

Domain: student

Registering to use the CBT Modules

Once you arrive at the proper course and click the LivePlay link to enter it, you will be prompted to register. The first time in (and until the server is working properly, perhaps additional times as well) you will enter the word "Self", and then you will be asked to enter a username and password.

  1. Use your own name as the username and a unique 5 digit number as your password.
  2. If you have to register multiple times, use the same username, but use a different 5 digit number as the password.

If you are using the CBT modules at home you will need to download a CBT player and install it on your home machine (be sure to download the correct player for your operating system - Windows ME users should use the player for Windows 98). The CIS labs should already have the player installed.

The CBT course modules for the CIS 235 course are:

  • Understanding and Applying Web Concepts
  • CGI and PERL
  • Javascript: Language Basics
  • Web Servers: Set up
  • Web Servers: Administration
  • Web Servers: Security
