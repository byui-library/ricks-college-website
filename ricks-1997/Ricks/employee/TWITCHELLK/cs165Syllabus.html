CS165 - Object Oriented Software Development
Syllabus

Software design and development using an object-oriented language. Algorithm formulation, an introduction to software engineering, and object-oriented programming.

The objectives of this course are to teach

  1. Requirements specification and design prior to writing code.
  2. Object-oriented design and software development fundamentals.
  3. Skills to prepare students to adapt as computer science and software engineering continue to evolve ("learn how to learn").

After completing this course, the student should be able to

  1. Learn new design technologies.
  2. Develop and analyze design alternatives.
  3. Apply problem solving techniques to programming.
  4. Describe the concepts relevant to the object-oriented approach to design and programming.
  5. Program using an object-oriented language language.

Prerequisites

  • CS 124 (Introduction to Computer Systems) or 144 (Introduction to Software Development)
  • Math 110 (College Algebra)

Required Text

  • Absolute C++ by Walter Savitch

Optional Reference Text

  • C/C++ Programmer's Reference, Second Edition by Herbert Schildt
