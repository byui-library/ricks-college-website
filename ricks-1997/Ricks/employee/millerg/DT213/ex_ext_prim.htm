DT 213 Exercise
Extended Primitives

 

The purpose of this exercise is to help you gain familiarity with many of the extended primitives available for object creation in 3D Studio Max. These include Hedra, ChamferBox, ChamferCyl, Capsule, Spindle, Gengon, L-Ext, C-Ext, OilTank, and TorusKnot.

Create all shapes inside a single 3D Studio Max model. Place the model in the DropBox when complete using the following naming convention: ExtPrim Your Name. Since there is only 1 file with this assignment there is no need to place it inside a folder.
