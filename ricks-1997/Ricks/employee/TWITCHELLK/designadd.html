Adding two integers supplied by a user

function main
   prompt the user to enter a positive integer
   read an integer from the user
   if the user input is positive (ie, greater than 0)
      prompt the user to enter a negative integer
      read an integer from the user
      if the user input is negative (ie, less than 0)
         add the two user inputs (the positive integer and the negative integer)
         output "The sum of " followed by the positive integer from the user
         output " and " followed by the negative integer from the user
         output " is " followed by the sum of the two integers
      else
         [the user did not enter a negative integer]
         output the value supplied by the user and state that the value is not negative
         output a suggestion that next time the user comply with instructions
         output a message indicating the program is terminating
      end if
   else
         [the user did not enter a positive integer]
         output the value supplied by the user and state that the value is not positive
         output a suggestion that next time the user comply with instructions
         output a message indicating the program is terminating
   end if
end function main
