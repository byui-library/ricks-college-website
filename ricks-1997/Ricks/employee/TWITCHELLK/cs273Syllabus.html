CS273 - Web Engineering
Syllabus

Internet and Web overview. Introduction to human-computer interaction. Information architectures. Client-server computing with client-side and server-side programming.

The objectives of this course are to teach

  1. Requirements specification and design prior to constructing a Web site and developing software.
  2. Elements of effective Web design including information architecture and usability.
  3. Web programming fundamentals, such that the students will be prepared to adapt as the Web continues to rapidly evolve.
  4. Skills in procedural and object based programming.

After completing this course, the student should be able to

  1. Design a Web site that is usable for a defined user population.
  2. Provide interactivity for Web users using client-side and server-side approaches.
  3. Program in JavaScript and Perl.
  4. Debug CGI software.

Prerequisites

  • CS 144 (Introduction to Software Development) or CS 165 (Object Oriented Programming) or CS 170 (Introduction to Software Development)
  • Familiarity with the World Wide Web, Web browsers, and e-mail is assumed
  • Familiarity with Linux is assumed

Texts

  • Learning Perl by Randal L. Schwartz and Tom Christiansen
  • Additional reference material is available on the Web
