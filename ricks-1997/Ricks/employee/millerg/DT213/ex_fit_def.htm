DT 213 Exercise
Using Fit Deformation in Lofting and Advanced Boolean Techniques

The purpose of this exercise is to help you gain familiarity with using fiit deformation and advanced boolean techniques to create complex objects easily. Use techniques as discussed in class and explained below to complete each problem.

Create each object in separate 3D Studio Max models. Put all models inside a folder using the key word Fit and place in the DropBox when complete.

Problem 1. Sports Car.
Create a model of the sports car shown below using the fit deformation lofting technique.

Problem 2. Fork.
Create a model of the style of fork that you most commonly eat with. Use the boolean extrusion technique discussed in class.

Problem 3. Dress shoe.
Create a model of one of your favorite Sunday shoes using the fit deformation lofting technique.

Problem 4. Phone handset.
Create a model of the handset portion of the phone in your apartment using the fit deformation lofting technique.

Problem 5. Ketchup bottle.
Create a model a ketchup bottle found in your apartment using the fit deformation lofting technique.
