Matrix Multiplication


"The test, then, of our soul's greatness is rather to be sought in our ability to comfort and console, our ability to help others, rather than in our ability to help ourselves and crowd others down in the struggle of life.", Joseph Fielding Smith.


Write a Qbasic program to multiply 2 matricies as explained below.

  • The program should prompt the user for the dimensions of the first array and then allow the user to interactively enter the array.
  • The program should next prompt the user for the dimensions of the second array and allow the user to interactively enter this array.   The program should perform a check when given the dimensions of the second array to make sure that multiplication is possible.
  • The program should then perform the multiplication and print out the resulting matrix in an easy to read format.
  • Your program should be able to handle any size of array.

Use the following data for your sample runs:

First Array
1 3 7 17 2
3 5 9 23 1
6 4 9 0 -1

Second Array
6 7 8
-2 -5 3
0 4 6
8 -3 7
6 14 -10
