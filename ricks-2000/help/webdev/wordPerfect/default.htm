Converting a WordPerfect File to HTML
This will assist you in converting a WordPerfect File to HTML

Converting a WordPerfect File to HTML
  1. Open the WordPerfect document.
  2. Click the File menu, choose Internet Publisher...

  3. Click Publish to HTML...

  4. Select where you what to save your files and click OK
  5. You will then need to open your documents in FrontPage or another HTML editor to ensure that everything looks the way you want it.
