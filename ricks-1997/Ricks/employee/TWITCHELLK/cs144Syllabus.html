CS144 - Introduction to Software Development
Syllabus

Algorithm formulation, problem solving, fundamental data types. Procedural paradigm of software development. Structured programming. Introduction to objects.

The objectives of this course are to teach

  1. How to develop software solutions.
  2. Programming basics.

After completing this course, the student should be able to develop and debug software written in the C++ language.

Prerequisite: Math 110 College Algebra (may be taken concurrently)

Text: Computer Science: A Structured Programming Approach Using C++ by Forouzan & Gilberg
