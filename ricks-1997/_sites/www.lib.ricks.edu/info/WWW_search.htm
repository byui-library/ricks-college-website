FINDING INFORMATION ON THE WORLD WIDE WEB

WWW SEARCH TOOLS

A. Web Directories: Web directories index a subset of the Web, broken down by categories much like a library catalog.

  • Usually these hand-picked sites are superior in quality to those found with a generic search engine.
  • Like search engines, Web directories have search fields where you can type a search term or phrase.
  • Directories are especially good if you are looking for lots of information on a single topic, or if you want to find several sites dealing with the same general subject.
  • Web directories index only a small portion of the Web, but they do it very well.

Examples: www.yahoo.com, www.webcrawler.com, www.ipl.org, www.mckinley.com, www.miningco.com, www.nlsearch.com, www.looksmart.com

B. Search Engines: Search engines are word-by-word indexes to pages on the Internet. However, even the biggest search engines only index 30-40% of the Web at most.

  • Search engines index a larger portion of the Web than directories (but still only 10-40% of the total).
  • Use a search engine if you are looking for a specific word or phrase, and you don’t care where you find it.
  • Use the search tips at the bottom of this page for best results.
  • Search engines will give you many more irrelevant and potentially undesirable hits than Web directories.

Examples: www.altavista.com, www.infoseek.com, www.excite.com, www.alltheweb.com, www.google.com, www.hotbot.com.

C. "Meta" Engines: "Meta" search sites allow you to search multiple search engines at once. This can be good and bad.

  • Meta sites search multiple search engine and Web directory sites all at the same time, increasing your chances of finding an obscure term or phrase.
  • However, the search engines they use might not be the ones you prefer.
  • They usually only retrieve the first 10 or so hits from each search site.
  • Before searching, they convert your search query to a "lowest common denominator" format for each of the search sites, which actually makes your search less specific.

Examples: www.metacrawler.com, www.dogpile.com, www.askjeeves.com ("Ask Jeeves" lets you type normal English sentences when searching.)

IMPORTANT TIPS FOR TYPING SEARCH TERMS

Most Web directories and search engine sites differ somewhat in the format ("syntax") they use for searches. Spending just 5-10 minutes on the Help screen of a particular search site can save literally hours in wasted time. One good approach is to learn to use 3 or 4 search sites well, and stick with them. Below are some search strategies that work at most search sites. These four steps will save a lot of time when looking for information on the Web.

  • Phrases — Use quotation marks around words that are part of a phrase: "Pearl of Great Price"
  • Capitalization — Use lower case unless you specifically want to find only upper case versions of the word.
  • Truncation — Many sites allow you to use the * symbol for right-hand truncation.

Example: "pacif*" will match on "pacific", "pacifier", "pacification", etc.

  • Boolean operators — Many sites have an "advanced" search mode that will let you use AND, OR, and AND NOT to narrow your search. It is best to type these operator words in all capital letters if you use them.

Instead of the boolean operators, many sites allow you to use + and - signs in front of words or terms to indicate AND and AND NOT logic, resp. (OR is automatically assumed by most search engines.)

For example, type this: +buffalo -"New York"

to look for the word "buffalo" but not the phrase "New York."
