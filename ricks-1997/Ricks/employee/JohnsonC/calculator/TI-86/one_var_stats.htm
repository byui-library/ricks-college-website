Single Variable Statistical Functions on the TI-86

To compute one variable statistics such as the mean, standard deviation, etc.
Edit the data:
[2nd] [STAT] [EDIT]
To clear out old data in the list(s), use the up-arrow key to select the list name and then press [CLEAR] [ENTER].  The old data will be gone forever.

Enter the data in the vertical list by typing the data value and pressing [ENTER] after each one.

Compute:
[EXIT] - Go to the home screen
[CLEAR] - Press clear if necessary to clear the line.
[2nd] [STAT] [CALC] [OneVa]
[2nd] [LIST] [NAMES] [Choose list name] [ENTER]

Press [EXIT] to hide the menus.
