CS145 - Software Design and Development
Syllabus

Introduction to software engineering principles with emphasis on design. Object-oriented paradigm of design and development.

The objectives of this course are to teach

  1. Requirements specification and design prior to writing code.
  2. Object-oriented software design.
  3. Skills in object-oriented programming using a language new to students.
  4. Skills to prepare students to adapt as computer science and software engineering continue to evolve ("learn how to learn").

After completing this course, the student should be able to

  1. Learn new design technologies and new languages.
  2. Develop and analyze design alternatives.
  3. Apply problem solving techniques to programming.
  4. Describe the concepts relevant to the object-oriented approach to programming.
  5. Program using an object-oriented language language.

Prerequisite

  • CS 144 (Introduction to Software Development)

Required Texts

  • Java, Java, Java: Object-Oriented Problem Solving by Morelli
