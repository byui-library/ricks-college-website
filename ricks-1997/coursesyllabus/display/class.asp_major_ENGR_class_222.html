C++ Programming and Engineering Numerical Methods
C METH:"C"LANG
CLASS CODE: ENGR 222 CREDITS:  3
DIVISION: PHYSICAL SCIENCE & ENGINEERING
DEPARTMENT: MECHANICAL ENGINEERING & TECHNOLOGY
GENERAL EDUCATION: This course does not fulfill a General Education requirement.
CATALOG DESCRIPTION: Introduction to programming and numerical analysis the C++ language applied to engineering analysis and design problems. Intended for students with experience in a structured high level computer language.
DESCRIPTION: Introduction to programming and numerical analysis of the C++ language applied to engineering analysis and design problems.
TOPICS: The course will cover computing concepts and program development in the C++ language as well as computer algorithms and numerical solution techniques common to engineering analysis and design.

OBJECTIVES: The student will learn to design and implement computer programs in the C++ language for the solution of engineering problems. This knowledge will be useful in developing custom programs for specific situations and in understanding the limitations of commercial application programs and libraries.
REQUIREMENTS: The homework will consist primarily of programming exercises, but some short answer assignments may also be given. It is expected that each assignment will be completed and turned on time. If an assignment must be late, please discuss the circumstances with the instructor before the due date. Late assignments will be subject to penalty. There may also be occasional quizzes. There will be no make-up or extra credit work.

There will be two tests given during the term plus a final test. These tests will be announced well in advance.
PREREQUISITES: Elementary course in structured programming and numerical methods in engineering analysis. It is assumed that class members have previous computer programming experience using a high level programming language (Engr 140 or equivalent). Review of the elementary concepts and syntax of the C++ language. Application of programming techniques as applied to engineering and technology.
OTHER: You will also need a computer disk for backing-up your work.
EFFECTIVE DATE: August 1994
