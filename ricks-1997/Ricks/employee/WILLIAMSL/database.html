You can download these databases and instructions:

1. FARS Query data explanation -- from the Fatal accident reporting system at NHTSA. This is a .pdf file.

2. Redskins record -- programming in Excel example.

3. Idaho's statewide candidate contributions. This is an excel spreadsheet with some 50,000 records or so. Useful for doing pivot tables.

4. Out of state contributions to statewide candidates. This is a smaller excel spreadsheet derived from the one above. Another pivot table device.

5. Idaho fatal accident data for 1999. This is FARS data in total. Useful for analysis of reporting figures.

6. Another, smaller collection of FARS data. For Idaho.

7. The classic deer database from NICAR. This is a good introduction to database analysis. Try this version too.

8. The Dam safety database. From a NICAR exercise.
