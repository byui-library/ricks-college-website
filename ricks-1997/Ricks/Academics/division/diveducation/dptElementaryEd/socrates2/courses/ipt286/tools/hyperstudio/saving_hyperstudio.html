Saving a Hyperstudio stack for Web Use

Saving your Stack | Plug-ins are Required

To get started, open the stack you want to post to the web in HyperStudio. Save the stack to your web folder or a desired sub-folder within your web folder. From HyperStudio's Extras menu, choose Export Web Page.

The Export Web Page will produce a small HTML document containing the necessary code to display a stack within your browser. You may need to enlist the help of the webmaster of the web server where your stack will be posted to get your stacks to serve properly. All necessary information can be obtained from the server configuration notes at www.hyperstudio.com. Socrates is configured to display your stacks.

HyperStudio users wishing to upload their presentations to the internet will have at minimum, two separate files that require posting to a web site:

1.FILENAME.STK. The .STK file is the presentation created with HyperStudio. It should be uploaded as uncompressed, raw data.
2.FILENAME.HTML. The .HTML file, generated by the Export WebPage extra, should be uploaded to the same location as uncompressed text.


Before uploading the .STK and .HTML files, try testing the execution locally, (open the .HTML file from your browser without being logged on). You may need to modify the .HTML file to reflect the exact path name(s) for the location of their stack within your web site's file structure. Of course, you will need to have the HyperStudio Browser Plugin installed to test locally. If the stack does not run, you may need to modify the .HTML embed source tag as follows:

embed src="PATHNAME/STACK.STK" [This modification would be done in the "Source view" of Pagemill 3.0]

Where PATHNAME is the exact path to your stack on your web/ftpserver and STACK.STK is the name of your stack

When creating a link to your stack from a different page, create the link to the Filename.HTML file, not to the Filename.stk file.

Remember, when you upload to the web server, you must upload both files, the .stk and .html files.

Plug-ins are Required

People will need two "plug-ins" in order to see your hyperstudio stack online. These plug-ins are:

Apple's Quicktime 3.0 or higher, and Hyperstudio's Plug-in.

Just as you did with your PDF files, you will probably want to forewarn a potential user that if they don't have these plug-ins, they will need them and then you create a link to take them to the appropriate location to download them.
