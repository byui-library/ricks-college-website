DT 213 Exercise
Using the Edit Mesh Modifier

 

The purpose of this exercise is to help you gain familiarity with using the edit mesh modifier to make modifications to existing objects easily. All of the objects pictured below were created using the standard primitives of Box, Sphere, and Cylinder and then applying Edit Mesh and using the standard transforms of move, rotate and scale.

Create each objects in its own 3D Studio Max model. Place the models inside a folder in the DropBox using the key word of Mesh.
