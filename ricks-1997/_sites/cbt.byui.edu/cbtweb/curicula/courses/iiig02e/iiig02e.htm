PC and Network Fundamentals

General Information

Course Duration
3 hours

Audience
End-users who want to learn the basics about PCs and networks

Prerequisites
 Basic computer literacy; an understanding of PC and network concepts, while not essential, would be useful

Topics Covered

PC architecture
  • CPU and memory
  • Disk and backup storage
  • Interfaces
  • I/O devices
  • Laptop components
Network architecture
  • The OSI model
  • Network basics
  • LAN technology
  • WAN technology
Software
  • operating systems
  • Network operating systems
  • NOS architecture
  • Applications

Course Aim

To familiarize the user with the internal components of a PC, network fundamentals, and software

Learning Objectives

After taking this course, the student should be able to

  • describe the components of PCs and explain how they operate

  • introduce network fundamentals and relate these to the ISO OSI model

  • outline LAN and WAN technologies

  • explain the functions of operating systems and network operating systems

  • describe the types of applications software available
