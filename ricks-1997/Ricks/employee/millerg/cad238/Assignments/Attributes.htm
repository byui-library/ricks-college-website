Using the attribute extraction capabilities of AutoCAD, do the following:

  • Create a template for extracting attributes using SDF format.  The file should include the block name, locaiton (x & y), NUMBER, VALUE, and COST.
  • Extract the attribute information using the newly created template file.


Turn In The Following:

  • 2 plots of schematic - 1 plot with all attributes displayed, 1 plot with attributes displayed normally.  Be sure to label the drawing appropriatelin and include an A-size titleblock.
  • Hard copy of template file and SDF formatted extraction file.
  • Electronic copy of template file and AutoCAD model.
  • Places all files in a folder, use the keyword ATTRIBUTE.
