Texas Instrument 89 Calculator Practice Sheet
Unit Conversions
Convert 5.6 feet to km. (ANS = 0.0017 km)

5.6, [2nd], [UNITS], [Length menu, scroll to _ft, ENTER], [2nd], [yellow arrow], [2nd], [UNITS], [Length menu, scroll to _km, ENTER], [ENTER] (You may find it is faster to simply type the sequence on the home screen.)

Temperature units are not converted like other units.
Convert –5.5 oC to oF. (ANS = 22 oF)

[CATALOG], [scroll to tmpCnv(, ENTER], [type: -5.5_oC,_oF)], [ENTER]
(You can quickly scroll within a menu by typing the first letter in the item you are seeking.)

Directories
When storing constants or equations, do not work in the HOME folder.
Create a CHEM folder.
[2nd], [VAR-LINK], [F1], [Scroll down to 5: Create Folder, ENTER], type CHEM, [ENTER], [ENTER]

You can select the folder you are working in by pressing [MODE] then selecting the desired current folder.

Constants
The TI has a number of built in constants. Find the value of Avogadro’s number, stored in the TI as Na. (ANS = 6.02x1023/mol)
[2nd], [UNITS], [Constants menu, scroll to _Na, ENTER], [ENTER]

Find the value of the speed of light, c. (ANS = 2.998x108 m/s)
[2nd], [UNITS], [Constants menu, scroll to _c, ENTER] [ENTER]

Storing Equations
Store the density equation as den=mass/vol.  Name the equation density.

[APPS], [Scroll down to 9: Numeric Solver, ENTER], type den=mass/vol in the eqn field, [F1] [Scroll down to 2: Save Copy As, ENTER], Select CHEM folder, type density in the Variable field, [ENTER], ENTER]

To return to the HOME Screen from APPS press [2nd], [QUIT]

Store the heat equation as q=sh*mass*(Tf-Ti). Name the equation heat.

[APPS], [Scroll down to 9: Numeric Solver, ENTER], type q=sh*mass*(Tf-Ti) in the eqn field, [F1] [Scroll down to 2: Save Copy As, ENTER], Select CHEM folder, type heat in the Variable field, [ENTER], [ENTER]

To delete a constant or an equation you have stored, [2nd], [VAR-LINK], [Scroll to the item you wish to delete, F1], [Scroll to 1:Delete, ENTER], [ENTER]

It is always a good idea to view an item before deleting it. To view an item after pressing [2nd], [VAR-LINK], scroll to the item of interest and press F6.

Using the Numeric Solver
Given that an object has a volume of 14 mL and a density of 4.5 g/mL, determine the mass of the object. (ANS = 63 g)
[APPS], [Scroll down to 9: Numeric Solver, ENTER], [F5], highlight desired equation, [ENTER], ENTER]

Once the equation has been entered and the variables are displayed in the solver:
1.    enter the known values for appropriate variables
2.    highlight the unknown variable with the cursor
3.    hit the [F2-SOLVE] key to solve for the variable.
