Write an AutoLISP program to insert a door into a wall as discussed in class and below.  The program should do all of the following:

  • Prompt for a door size

  • Display/update a default door size

  • Allow for 4 types of doors (LH, RH, LHR, RHR) based on the digitize

  • "Break" the existing line

  • Construct the door from a line and an arc


Use good programming techniques as discussed including the following:

  • Use loops to allow the proram to automatically repeat.  A simple carriage return should allow a graceful exit.

  • Eliminate all unnecessary AutoCAD prompts and nil values

  • Good documentation

  • Executable as an AutoCAD command

  • Concise - use good internal code, eliminate duplications, etc.

  • Use local variables as appropriate
