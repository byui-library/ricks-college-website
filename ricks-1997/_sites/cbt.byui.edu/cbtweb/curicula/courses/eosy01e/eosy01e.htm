Enterprise Operating System Principles

General Information

Course Duration: 4 hours

Audience: IS management, network management, network support, and sales support staff

Prerequisites: Familiarity with the course LAN Fundamentals

Topics Covered

Network operating systems principles
  • Networking models
  • Network operating systems
  • The administrator's responsibilities
Desktop operating systems
  • Microsoft networking clients
  • NetWare clients
  • UNIX clients
  • OS/2 clients
  • Apple Macintosh clients
Interoperability
  • Protocols
  • Redirectors
  • Gateways
  • Platform independence
Distributed computing
  • DCE
  • CORBA
  • DCOM
Networking trends
  • Directory services
  • Internet integration
  • System management
  • Functionality enhancements

Course Aim

To provide users with an understanding of enterprise operating systems, and an understanding of management and interoperability issues as part of an overall network strategy

Learning Objectives

After taking this course, the user should be able to

  • describe current networking models
  • list standard network administration requirements
  • outline the key features of the leading operating systems on the market
  • outline network integration issues
  • outline some current network trends
