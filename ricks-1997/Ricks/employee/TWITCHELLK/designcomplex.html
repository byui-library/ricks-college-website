Testing a complex number class

class Complex
   private:
      floating point variable for the real part of the complex number
      floating point variable for the imaginary part of the complex number
   public:
      constructor with default values of 0.0 for the two parameters
         receives two floating point values: the real and imaginary parts of the complex number
         copy supplied (or default) real and imaginary values into private data variables
      end constructor with default values of 0.0 for the two parameters

      function getReal with no parameters
         returns the real portion of the complex number
      end function getReal

      function getImaginary with no parameters
         returns the imaginary portion of the complex number
      end function getImaginary
end class Complex

operator overload of + for complex numbers
   receives two complex objects
   get the real values of the two complex objects and add them
   get the imaginary values of the two complex objects and add them
   use the summed real and imaginary values as parameters to instantiate a new complex object
   return the instantiated complex object containing the sum
end operator overload of + for complex numbers

operator overload of << for complex numbers
   receives an object of the destination of the output and a complex number
   get the real value of the complex object (the a of a+bi)
   get the imaginary value of the complex object (the b of a+bi)
   output the complex number in the form of a+bi
   return the object of the destination of the output (so output can be chained)
end operator overload of << for complex numbers

function main
   [purpose is to test complex class and operator overloading]
   instantiate a complex object using arbitrary values
   instantiate a second complex object using arbitrary values
   output each complex number to demonstrate operator overload of <<
   output their sum in the cout statement to demonstrate operator overload of +
      (and that it correctly returns a Complex object)
end function main
