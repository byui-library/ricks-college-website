Single Variable Statistical Functions on the TI-85

To compute one variable statistics such as the mean, standard deviation, etc.
Edit the data:
[STAT] [EDIT]
Press [ENTER] twice to accept the current list names.  Otherwise select different list names from the menus.

To delete old values from the lists, choose [CLRxy]

Enter the data list by first entering each data value and then pressing [ENTER] twice.   This assumes each value occurs once or is to be entered individually.  If the data involves counts of occurrences, use the y-values to record the frequency of each occurrence.

Compute:
[2nd] [CALC] [ENTER] [ENTER] [1-VAR]
