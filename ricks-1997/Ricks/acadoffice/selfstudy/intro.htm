    Installation Instructions for Windows Platforms

    1.    A file containing the Acrobat Reader software [acro32 (windows).exe] should have
           been saved to your hard disk.

    2.    Quit your Web browser.

    3.    Double-click the newly downloaded file.

    4.   Follow the instructions on your screen.

    If there is a failure at any point during the installation of Acrobat Reader, the installer
    performs a complete uninstall. For this reason, it is important not to close the installer application by clicking its close box in the upper right corner of the background window after clicking the "Thank You" dialog box that appears at the end of the installation. If you wait for a second or two, the installer will automatically close the background windows after the installation is complete.

Installation Instructions for Macintosh Platforms

1.    A file containing the Acrobat Reader software [acro32 (mac).bin should have been
       saved to your hard disk.

2.    Quit your Web browser.

3.    The file you download will be expanded to a self-extracting archive. If your Web browser
       isn't configured to automatically launch an application such as StuffIt Expander(TM) to
       expand .hqx or .bin files (which is available as a freeware product and is distributed with
       Netscape(TM) Navigator(TM) 3.0 or later ), you'll need to manually launch an application
       to expand the downloaded file to produce Reader 3.01 Installer.

4.    Double-click the file. (Note: This will cause all current Mac applications to quit.)


5.    Follow the instructions on your screen.
