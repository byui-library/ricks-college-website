Cubing an integer read from a file

function cubedInteger
   receives a pointer to the integer value to be cubed
   returns an integer, the cube (value * value * value) of the supplied integer
end function cubedInteger

function main
   open file "number.txt" for input
   read an integer value from the input file
   close the input file
   output "The cube of " followed by the integer value from the input file followed by " is "
   output the return value from function cubedInteger, passing it the address of the input value
end function main
