DT 213 Exercise
Lofting

The purpose of this exercise is to help you gain familiarity with using the lofting command to create complex objects easily. All of the objects pictured below were created using only basic lofting techniques. Each object uses either a straight or curved path and basic shapes of circles or rectangles. Deformations of scale, twist, teeter, and bevel have been applied to selected objects as listed below.

Create all the objects inside a single 3D Studio Max model. Place the model in the DropBox when complete using the key word of Loft before your name. Since there is only 1 file with this assignment do not place it inside a folder.
