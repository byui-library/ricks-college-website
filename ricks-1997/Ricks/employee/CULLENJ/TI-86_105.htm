TI-86 CALCULATOR (revised 9/16/97)                                     "PANIC" button = EXIT

I.     Store, retrieve, delete a number:

        1.     To store: (enter number), STO, (name), ENTER

        2.     To retrieve: 2nd , RCL, (name), ENTER or 2nd, CATLG/VARS, REAL, (find variable), ENTER, (ENTER)

        3.     To delete: 2nd, MEM, DELETE, REAL (or MORE to find EQ if you want to delete an equation), (find variable or 
                equation), ENTER, EXIT.

WARNING: Each time you hit ENTER, you will delete what the cursor highlights!

Practice: Store B = 40, multiply 3B, delete B

II.     Store an equation:

    1.     (Name of equation - use ALPHA to produce letters), = ,

    2.     (type equation - use more than one letter for each variable, don't use same name for variable and equation name, if you
            want lower case letters (2nd , ALPHA) Greek Letters (2nd , CHAR, GREEK, then use appropriate key)), ENTER.

Practice: Store the following using contractions of the variable names if you want. Just be sure that the equation name and a variable name are not the same.

DENSITY = MASS/VOLUME as DENS, HEAT = MASS*SPECIFICHEAT*T as HET, ln (P2/P1) = -H/R (1/T2 - 1/T1) as CLAUS

III.     Using the Solver:

    1.     2nd , SOLVER, CLEAR

    2.     2nd , RCL, (select equation, use MORE if necessary to find), ENTER, ENTER

    3.     (enter known values, highlight unknown), SOLVE.

    4.     Sometimes it is necessary to give the variable you are solving for an initial quess before you solve. This is always
            necessary if the variable to be solved for is in the denominator of a fraction.

Practice: Find VOLUME if DENSITY is 0.78 and MASS is 35. (Ans: VOLUME = 44.87) Find HEAT if T is 25, SPECIFICHEAT is 4.18, MASS is 40. (Ans: HEAT = 4180) Find T1 if P2 is 700, H is 40000, R is 8.314, P1 is 100, T2 is 400. (Ans: T1 = 344)

IV.     Scientific notation:

    1.     2nd , MODES, select SCI, ENTER, EXIT. Calculator will now display all numbers in scientific notation.

V.     Unit Conversions

    1.    2nd, CONV , (select Units Directory)

    2.     (Enter number - put () around negative values), (select unit, select unit to convert to), ENTER

Practice: Convert 50 grams into amu (Ans: 3.01 x 1025) Convert 10 fathoms into meters

(Ans: 18.3)

VI.     Retrieving Constants

    1.     2nd , CONS, BLTIN

    2.     (Select constant), ENTER
 

VII.     Adding Your Own Constants
 

    1.     2nd , CONS, EDIT

    2.     (Give a name), ENTER, (give a value), ENTER

    3.     EXIT

Practice: Add Ratm = 0.08206, Rmm = 62.36, molV = 22.414, FARADAY = 96485

VIII.    Retrieving Your Own Constants

    1.     2nd , CONS, USER

    2.     (Select constant), ENTER

Practice: Retrieve molV

IX.     Linear Regression (finding equations of lines):

    1.     STAT, EDIT

    2.     If you don't want to save the data, move cursor to xStat in the column heading, CLEAR, select { from the screen, then
            enter x variables separated by a comma, close with }, ENTER.

            Repeat for yStat.

    3.    If you want to save the data, move cursor to xStat in the column heading, 2nd INS (this will add a column), enter an
           appropriate name for the x variable, ENTER, { enter x values separated by commas}, ENTER. Move cursor to xStat
           again, 2nd INS, and repeat the preceding operations by now for the y variable. The data are now saved for further use.
           The inserted columns can be deleted from the screen if desired (but not from memory) by moving cursor to column
           heading and pressing DEL.

    4.    STAT, CALC, LinR (for straight line) x variable, y variable. The names of the x and y variables can be taken from
           LIST. Then ENTER

    5.     a = intercept of line
            b = slope of line
            corr = correlation (the closer to + or - 1 the better the straight line
            n = number of data points

VI.     Graphing regression line:
 

    1.     GRAPH, WINDOW, set xMin to 0 or value close to smallest x value, set xMax to maximum x value, do the same for
            yMin and yMax, EXIT

    2.     STAT, PLOT, PLOT1, select ON ( you will need to turn it off to do functions again), down arrow to xStat, enter
            name of x variable if other than xStat, down arrow, do the same for yStat, EXIT.

    3.     STAT, DRAW, MORE, DRREG.

VII.     To predict values

    1.     STAT, MORE, FCST, enter either x or y value, move cursor to other variable, SOLVE
