HTML-Kit Setup Directions

Downloading the Default page file

HTML-Kit has the ability to establish a new file of a particular type (e.g. xhtml transitional). By default the file type is HTML-Strict. You will download a file, execute the file, and configure HTML-Kit to use the file as a template for all further files generated by the program.

  1. First you must download the executable file that contains the code, or this document can be found at Jupiter/IS/robertsonb/xhtml.htm on campus.
  2. Indicate where you want the executable file saved (Desktop is recommended).
  3. When saved, double-click the executable. It will, by default, attemp to save the file to your H:\ drive. On campus this is correct; however, if doing so for home you will have to browse to a different location.
  4. When the file is extracted, you can delete the executable version.

Configuring HTML-Kit to use the data from the downloaded file

  1. Open HTML-Kit
  2. From the Edit menu select Preferences.
  3. When the Preferences window opens, click the Startup tab.
  4. On the right click the "Import from file..." button.
  5. Browse until you find the xhtml.htm file (this is the name of the downloaded file). Double-click it.
  6. The text from the file should now appear in the text field box above the "Import from file..." button.

Setting the Word Wrap Parameters

To help with readability of your code you should establish word wrap criteria:
  1. Click the Editor tab in Preferences.
  2. In the Word Wrap Options box (right-middle)turn on all 3 checkboxes.
  3. Set the word wrap column to 80 characters.

Setting HTMl Tidy preferences

Tidy does checking and converting to xhtml from html.
  1. Click the TIDY tab
  2. Change the word wrap setting to 80 characters (bottom-left).
  3. Change the DocType setting to "Loose" (right-middle).
  4. Turn on the following Switches (Scrolling text box on left):
    1. Convert " marks to & quot;
    2. Convert ampersand to & amp;
    3. Convert I and B to em and strong
    4. Strip surplus tags in Word 2000
  6. Click OK to have these preferences saved.

Establishing a Local workspace

A workspace is where your data is stored and accessed from HTML-Kit. For IS 235 it will be a folder on your data drive (the H: drive on campus). This will allow you to develop materials locally and when they are ready to distribute them to the WWW.
  1. On your data drive (usually H:) create a new folder. Name it your own last name and first initial (e.g. John Smith = smithj) using all lowercase letters and no spaces.
  2. Within HTML-Kit select "Add Local/Network folder..." from the Add FTP Server/Local Folder option within the Workspace menu.
  3. Within the Add Folder window, click the browse folder icon to the right of the Folder Location text box. Browse to your data drive and select the folder you created in step 1 of this process.
  4. The path and folder name will appear (e.g. H:\smithj\).
  5. Click the Name text field. It should autofill with the same path as in the location field. Accept that input and click the General tab.
  6. Input the web address of where the files will ultimately be stored for web distribution. For IS 235 the path should be http://mars.byui.edu/robertsonb/is235/f02/[your own last name and first initial]/ . You must make sure that your last name and first initial are lowercase and no spaces!
  7. Accept all other default settings and click OK.
  8. Your folder should appear to the right of the normal canvas area in HTML-Kit under the Files tab.

Establishing a Remote workspace

A remote workspace is a link to your share on the web server. This is where you will ultimately save your work for distribution and access on the WWW. In HTML-Kit there are two options for establising a remote workspace: FTP Server or Local/Network Folder. For security reasons we will use FTP Server.
  1. Within HTML-Kit select "Add FTP Server" from the Add FTP Server/Local Folder option within the Workspace menu.
  2. The Add FTP Server window opens and the FTP properties tab is active.
  3. The server path is mars.byui.edu
  4. The username is students\[your network username]
  5. Do NOT enter a password and turn off the Remember password option.
  6. Click in the Display Name text field. It should autofill, accept it.
  7. Click the Initial Directory text field. Enter the following path: /robertsonb/is235/f02/[your last name and first initial] / . You must make sure that your last name and first initial are lowercase and no spaces!
  8. Click the General tab. Enter the following address in the Web root address field: http://mars.byui.edu/robertsonb/is235/f02/[your last name and first initial]/ . This allows HTML-Kit to know the root location of your web folder for preview and download purposes. Accept all other default settings.
  9. Click OK.
  10. Your FTP server should appear (in blue) to the right of the normal canvas area in HTML-Kit under the Files tab.
  11. To connect to the server double-click the mars.byui.edu icon. A dialog box appears asking for you password. Enter your regular network logon password. The connection should then be made giving you access to your share.
  12. To disconnect from the server, right-click the mars.byui.edu icon. Select Disconnect from the options menu.

Uploading Files

To upload files to the remote FTP server (mars.byui.edu) from within HTML-Kit, do the following:

  1. Right click the mars.byui.edu icon.
  2. From the Options menu select "Upload"
  3. When the Open dialog box appears, browse to the location where file to be uploaded is stored.
  4. Click the file, or Control + Click multiple files, to be uploaded to the FTP server and click Save.
  5. The files should be uploaded to the server and should now display in the FTP list in the files window on the right of the screen.
