Using Technology in the Classroom 

Technology has been in the classroom almost since the "classroom" was started.   Learn what types of technology are best for specific learning outcomes.
- What would make it worth my time to create multi-media presentations?
- When is it more effective to use a whiteboard?
Learn advantages and disadvantages of various technologies.  Also, learn tips and techniques for effectively and efficiently using common classroom technologies, like whiteboards, overheads, video, and computer presentations.
