CS102 - Introduction to Computer Science
Syllabus

Provides information to help a student determine if he/she would like to major in Computer Science. Basic concepts of Computer Science, software engineering, and software development.

The objectives of this course are to expose the potential computer science major to

  1. The field of Computer Science.
  2. Computer Science curriculum requirements.
  3. Professions associated with Computer Science.
  4. Software development.

After completing this course, the student should be able to

  1. Describe Computer Science.
  2. Understand Computer Sciences basics such as algorithm development.
  3. Develop simple programs using JavaScript.
  4. Determine appropriate Computer Science courses to take.

Topics

  • Overview of Computer Science
  • Career Options
  • Computer Science Curriculum
  • Other Computer Majors
  • Introduction to Unix
  • Algorithms
  • Programming Fundamentals

Prerequisite(s)

  • high school algebra
