Sending E-mail Attachments

These directions assume that you are using the Ricks College student e-mail client found at Neptune.ricks.edu.

1. Using an application create and save the document that will be the attachment to your disk or H: drive.

2. Open the Ricks College Student e-mail client by opening your web browser (Internet Explorer or Netscape Navigator).

3. In the Address or Location bar type Neptune.ricks.edu and press the Enter key (The Student client window should appear).

4. Type your username and password in the appropriate location and press Enter.

5. You should now be in the Menu area. Click the Compose button on the left.

6. In the address line enter the address of the person to receive the email (e.g. robertsonb@ricks.edu).

7. In the subject line enter a brief description of what the message is about (e.g. email assignment). Remember that if you are submitting an assignment to Br. Robertson the word "Assignment" must appear in the subject line.

8. A message in the message area is optional.

9. When ready to attach an external file, click the Attach button on the left of the screen.

10. To attach a document is a two-step process.

    Step 1 - Click the Browse button.

  • Navigate to where the document mentioned in #1 above is stored.
  • Double-click the file name or icon, or click it once and click the Open button.
  • The path to the file will appear to the left of the Browse button.

    Step 2 - Click the Attach button to the right of the Browse button.

11. The window should move to the top of the page (You should see the address and subject information).

12. Using the vertical scroll bar, move to the bottom of the page and visually check that the file name appears in the attached documents box (between the Browse and Attach buttons).

13. If the file name appears in the attached files box, use the vertical scroll bar to move back to the top of the page.

14. Click the Send button to send the email message and a copy of the file as an attachment. It will not send the original document, only a copy. If you desire to send more than one attachment, repeat step 10 for each attachment.
