Microsoft FrontPage, Beginning

The Ricks College standard for web page creation is Microsoft FrontPage.  Learn the basics of FrontPage, how to post it on the Ricks College Internet, and how to make some sense out of all the Internet jargon.  Workshop will include information on creating a new web page, adding text and graphics to a page, and creating hyperlinks.  Workshop will also include Tips and Tricks for great looking web pages (and what not to put on the web).
