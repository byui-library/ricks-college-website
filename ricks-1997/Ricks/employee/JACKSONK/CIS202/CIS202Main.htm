Course Description

Visual programming environments (e.g., Delphi, JDeveloper, Visual Basic, etc.) allow a programmer to develop software
applications that take advantage of the graphical user interface in the windows environment. These applications often become
the front end for many Client/server applications that are being widely used in businesses today. Such applications may be divided across multiple hardware platforms. The client portion typically provides the user with a graphical user interface in the windows environment that makes request to a server computer where the data is stored in a database.

This is an introductory course in visual programming. You will learn how to develop algorithms for complex programming problems, create software applications that take advantage of graphical interface of the windows environment, and develop client/server applications that accesses a data base management system on a remote server computer.

Objectives

  1.    Be able to develop algorithms for complex programming problems
  2.    Develop Windows based end user interfaces using the Delphi product.
  3.    Use all of the base controls structures and basic data types of the Object Pascal language.
  4.    Build a client/server application that accesses data from a database management system on a remote server.
  5.    Be introduced to object oriented programming.
