Helpful Hints for Installing and Using Acrobat Reader

  • Click on the Get Acrobat Reader button to download the installation file.
  • As you download the installation file for Acrobat Reader, keep track of the folder where the file is saved.
  • Open the folder the file was downloaded into and double-click on the file to begin installation. (You can use Windows Explorer or the Run option on the Start button to find the file.) 
  • In the installer, several setup screens will appear. Carefully read and follow the instructions on each screen. 
  • You will be asked to restart your PC after installation is complete.  Shut down your PC and re-start it.  Acrobat Reader is now ready for use.
  • Click on the Open The Application Form link and Acrobat Reader will automatically be launched.  The first time you use Reader, you will see a license agreement screen.  Read the agreement completely and click Accept if you agree to meet the terms of use. 
  • The application form will be opened and can be printed for use.
