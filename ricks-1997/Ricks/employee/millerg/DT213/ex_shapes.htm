Shapes

The purpose of this exercise is to help you gain familiarity with many of the shapes available for object creation in 3D Studio Max. These include Line, Circle, Arc, Ngon, Text, Rectangle, Ellipse, Donut, Star, and Helix.   Create all shapes inside a single 3D Studio Max model.  Place the model in the DropBox when complete using the following naming convention:  Shape Your Name.  Since there is only 1 file with this assignment there is no need to place it inside a folder.
