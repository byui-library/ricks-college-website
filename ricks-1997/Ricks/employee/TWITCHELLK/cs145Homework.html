05 Change Maker
50 points
     Create a Java application to output the change from a purchase. Prompt the user to enter a non-negative integer less than or equal to 100 (e.g., 85). After reading the number from the user, instantiate a ChangeMaker object (passing the constructor the user input). The object calculates the amount of change from $1 (100), assuming that the user input represents the cost of an item in cents and determines the least number quarters, dimes, nickels, and pennies to be used as change. Invoke an accessor method to output "The item costs ### cents." where ### is the value input by the user. Follow this with the change specified as quantities of quarters, dimes, nickels, and pennies. You may not use any selection or iteration structures. Assume user input is valid.

  • Enter the cost of an item in whole cents (0-100): 59
    The item costs 59 cents.
    Your change is 1 quarter(s), 1 dime(s), 1 nickel(s), and 1 penny(ies).
  • Enter the cost of an item in whole cents (0-100): 5
    The item costs 5 cents.
    Your change is 3 quarter(s), 2 dime(s), 0 nickel(s), and 0 penny(ies).

11 Sorts of All Sorts
600 points
     Create a (stand-alone) Java application that sorts two-dimensional arrays. Implement the following three sorting algorithms: bubble, selection, and insertion. Implement the algorithms explained in class.
     Use inheritance to avoid duplication of code. The super class shall have all common code required by all three sorting algorithms. There shall be one subclass for each sorting algorithm.
     Create a three (row) by five (column) two-dimensional array. Fill it with random numbers ranging from 32 to 64. Sort the array so that
  • the smallest value is at index [0][0],
  • the next smallest value is at index [0][1],
  • the third smallest value is at index [0][2],
    ...,
  • the third largest value is at index [2][2],
  • the second largest value is at index [2][3],
  • and the largest value is at index [2][4].
     For each sort, output
  • the array before the sort as three rows and five columns and
  • the array after the sort as three rows and five columns.
Appropriately identify each section of your output to maximize readability.
     You may not use a one-dimensional array, or anything like unto it, anywhere in your program. Your implementation will not be considered to be anything like unto a one-dimensional array as long as the initialization, sorting, and output of the two-dimensional array always uses both dimensions (row and column) and you always use nested loops to set the row and column coordinates.
