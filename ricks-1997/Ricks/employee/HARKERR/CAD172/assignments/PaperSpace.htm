Create a drawing of the object below using PaperSpace as discussed in class. Begin by creating the object as a solids model. Use the SOLVIEW and SOLDRAW commands as required to create viewports and hidden line views. Include 3 orthographic projections (top, front, and right side) and an isometric view of the object. Orthographic views should be shown with hidden lines dashed, while the isometric should be shown with hidden lines removed.

Turn in a Full Scale plot (B-sized titleblock).  Make the isometric view 3/4 scale. You may omit dimensions and center lines.  No electronic copy will be required.
