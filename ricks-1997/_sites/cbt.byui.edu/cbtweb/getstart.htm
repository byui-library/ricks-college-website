Getting Started with SmartForce Web


What is SmartForce Web?

SmartForce™ Web is a system for deploying SmartForce courseware over an intranet. It has been designed to allow students to locate and launch SmartCourses easily, using their web browsers. It also allows administrators to track student usage of their training library and to monitor student progress.

How does it work?

SmartForce Web is presented like a typical web site, with linked  HTML pages, so that students and administrators can navigate their way around the product easily. Once the student has found the course they want to study, they simply click the LivePlay icon and the course starts to play.

Getting started

It takes just two steps to get started:

  1. Download and install the Player on your computer. This is described in the Required components section below.
  2. Find the course you want to take and launch it through your web browser. This is described in the Accessing a course section.

Required components

If this is the first time you've used SmartForce Web, you will need to download and install the Player. You need to do this only once, since the Player works with all SmartCourses and can be used repeatedly. To download the Setup program, click the appropriate link below:

Windows® 95, Windows® 98, and Windows NT® users click here

Windows® 3.x users click here

Once you've downloaded the Setup program, you need to run it to install the Player on your computer.

Accessing a course

To access a SmartCourse using SmartForce Web, first click the Courseware hyperlink on the home page. This will bring you to the Courseware page, which displays a graphic of the SmartForce e-Learning Catalog. From the Courseware page you can quickly find a course to play by clicking the list of available courses link.

Alternatively, by clicking one of the hotspots on the Catalog graphic you can navigate through the SmartCourse library, browsing information on curricula and the courses in each curriculum. You can even find out exactly which topics are covered in a course and the number of study hours it entails.

To take a course online, navigate to its course description page and click the LivePlay icon. The course starts up, its front screen displays, and you can start working through the units.

Note: If the course has not been made available to you, there will be no LivePlay icon on the course description page. You can request the course from your training administrator.
