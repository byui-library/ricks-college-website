Microsoft Office 2000: New Features for Power Users

General Information

Course Duration: 4 hours

Audience: Office 97 users who wish to learn about the new advanced features of Office 2000 including web integration

Prerequisites: Completion of all courses in the Microsoft Office 97 curriculum or equivalent familiarity with Office 97 and completion of Microsoft Office 2000: New Features for Users

Topics Covered

  • Collaboration
  • Hands-on: Using a theme
  • HTML and web support
  • Web discussions and subscriptions
  • Integration into Office
  • New developer features
  • Hands-on: Setting HTML preferences
  • Site and project management
  • Excel corporate reporting
  • PowerPoint
  • Access
  • PhotoDraw
  • Using PhotoDraw
  • Hands-on: Customizing a graphic
  • Publisher
  • Using Publisher

Course Aim

To describe the new web integration and collaboration features of Office 2000 and other features of interest to power users


Learning Objectives

After taking this course, the user should be able to
  • understand the collaboration features of Office 2000

  • save Office documents as HTML and publish directly to web sites

  • use the new features of FrontPage 2000

  • use the advanced new features of Excel, PowerPoint, Access, and Outlook

  • create documents and graphics using Publisher and PhotoDraw


Course Incorporates: Test, hands-on exercises
