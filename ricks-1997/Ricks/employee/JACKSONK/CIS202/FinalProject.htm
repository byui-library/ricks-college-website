Final Project

The final project is designed to give you the experience of working in a real world situation where you typically work in teams to complete a programming project. The success of these projects requires both team work and individual effort.

The scoring of the final project is designed to encourage you to work together with your team and to do your fair share of the project. The team has a whole will receive a single score for the project. This combined team score is then used as the basis for calculating your individual score for the project.

Scoring the Project

Evaluation

Your grade for the team project will be based upon a combined team score and your individual participation score. The combined team score for the project is based on the criteria below. Your individual participation score is based upon the teacher's evaluation of your contribution to the project. Individual time logs, interviews and observation will be used to determine this evaluation.

Project Proposal 100

Design Specification 400

Completed Delphi Program 600

Total 1000

Time Logs

Each member of the team is required to keep a time log of all activities that they work on for the project. This log is used to determine your individual contribution to the project. The log is to be updated, and signed by the team leader and turned in with your project notebook for each team assignment and design review. The log must list each activity you worked on, the date you worked on the activity and the amount of time you spent on the activity.

A Microsoft Excel spreadsheet is provided for your time log. Copy the following spreadsheet file to a 3.5" diskette: R:\jacksonk\cis202\CIS202 time log.xls. All log entries must be recorded in this spreadsheet file.

 

Project Phases

Project proposal (100 pts.)

This is a two-page paper describing the function and scope of your final project in detail. The instructor must approve the project proposal before proceeding on with the design specification.

Design specification (400 pts.)

The design specification contains:

    • Prototype designs for each form and report being used (100 pts.),
    • A menu tree showing how to navigate through the system (100 pts.),
    • A detailed design for each database table (100 pts.),
    • Pseudocode for each procedure (function) that will contain more than two lines of code (100 pts.)

The instructor must approve the design specification before moving on with this phase of the project

A Working Delphi Program (500 pts.)

The working program that you implement must follow your design specification. The entire team will demonstrate their project to the rest of the class on the scheduled final exam time for the class. A print out of each form, each report, and the source code for each unit file are to be placed in the project notebook along with all previous work and turned in upon completion of the demonstration of the project.

Program Requirements
  1. How closely the final program follows the design specification (50 pts.)
  2. Demonstration of a fully functional working program (50 pts.)
  3. The use of the following elements:
    1. The use of at least three different primitive data types (10 pts.)
    2. A mathematical expression using mathematical operators (10 pts)
    3. Two different types of selection statements (40 points)
    4. One or more repetition statement/s (40 points)
    5. Use at least one of each of the following components: button, edit box, menu, radio buttons or check boxes, a list box or a combo box, and an image (60 pts.)
    6. Use any two other component of your own choosing (20 pts.)
    7. Use one standard Windows dialog: Font, Color, Print, Etc. (50 points)
    8. Use a key to locate a specific record in a database (30 pts.)
    9. Use an index to order the records displayed in a table (30 pts.)
    10. Use a range to locate a group of records in a database (30 pts.)
    11. Use an SQL query to join two or more tables and locate a group of records that satisfies one or more conditions (30 pts.)
    12. Use the QuickReport component or ReportSmith to create and print a report. (50 pts.)
