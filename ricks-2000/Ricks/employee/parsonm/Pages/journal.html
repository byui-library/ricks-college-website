9-12-01:www.completeplanet.com(tutorials/Search/index.asp) XHTML makes everyone code the same way. A browser reading XML will read XHTML but not HTML 4.0. Leaving out the "XML" declaration will let the browser do whatever it wants with the page. The "Doctype" declaration also tells the browser to conform and read it exactly as it is written. There are various kinds of XHTML doctypes:

XHTML 1.0 Strict:-only elements, attributes, and values defined in the XHTML 1.0 recommendations are used -nothing deprecated or obsolete is ever used. Style is removed from document formatting. Depreciation of style tags in favor of style sheets. -recommendation to use style positioning over table grids for layout.

XHTML 1.0 Transitional:-allows the use of tags from HTML 3.2 and HTML 4.01. -Allows the use of presentational markup, such as the font element. -encourages the use of style sheets. -Allows simultaneous use of style sheets and presentational markup.

XHTML 1.0 Frameset: -Exists to create valid framesets in accordance with XHTML 1.0. -Allows the use of transitional and strict XHTML 1.0. -Adopts new HTML 4.01 elements into the standard: frame, frameset, noframes, and iframes.

About XHTML: Element <tags> can be either nonempty or empty. A nonempty tag has content where a empty tag simply points to another object. the <p> tag is nonempty because it contains content.  It is important to consider symmetry in creating your XHTML documents. Both horizontally and vertically in the order and positioning you use in placing your tags. Attributes always come in the opening tag. Never in the closing. For example: <body bgcolor="red" text="black"></body> Attributes are always separated by spaces in HTML and there must not be any spaces within the attribute itself. Values should always be in quotes.  Hexadecimal colors designated by "#000000" can be used or there are 126 colors designated by browsers by name. Everything should be keyed in lower case.

Regarding colors and images:  Use images only to portray more succinctly what you are trying to portray with the sight. Keep the images as small as possible to minimize the download time.  Save the picture small, don't save it big and shrink it on the page. *"jpeg" (joint photograph expert groups) files give better colors with a smaller file size. Good image quality. They can be compressed to different levels but it pulls out some of the colors. *gif (graphic interchange format) files are the most commonly used on the web. They have much less color depth and appear much more grainy. They can be made transparent and can be made animated as well. They can be saved to download as interlaced or non-interlaced. Non-interlaced: takes longer to load but less memory. This way loads the picture one row of pixels at a time from top to bottom. Interlaced: loads the whole picture all at once adding colors in steps. Takes much more memory. *png (portable network graphic) files have much more color support then either jpeg or gif and require more memory but are not largely supported by the browsers.
