HTTP

HTTP (HyperText Transfer Protocol) is a protocol type. A protocol is a set of rules that governs communications between two computers. There are other protocols that are used within a WWW browser. Some of the common protocols and their uses are:

  • http: Accesses WWW resources on a server.
  • gopher: Accesses text-based resources that are organized in heirarchical order.
  • ftp: Allows connections to, and ability to download or upload files from or to remote servers. Using a web browser, ftp: usually allows only download capabilities.
  • Mailto: Indicates to the browser to send e-mail to a specific internet address. Not all browsers support this protocol.
  • News: Accesses news groups, using news browsers. You must have newsreader capability within the browser.
  • Telnet: Accesses telnet software, separate from your browser, that allows you to form a plain-text connection to another computer (making it behave as if you were setting at that computer, operating it), and access large databases that might be otherwise difficult using a different connection type.

HTML Code - The Basic Elements

Images

  1. HTML documents will accomodate only .GIF (8 bit color depth display) or .JPEG (24 bit color depth display) format types. Be sure that all image types are in one of these two documents.
  2. If you have a image that is another format type, use GraphicConverter (Macintosh) or PixWizard (Windows) to change it.
  3. Images should be as small in memory size as possible, while retaining image quality.
  4. Less than 40Kb is the norm.
  5. Never more than 100Kb.
  6. Use 256 colors (8 bit color depth), and dither the image.
  7. Dithering allows the computer's color table to "cheat" when filling in colors that it may not be able to actually support, thus giving you a better picture.
  8. Crop pictures to display the elements that are essential to convey your message.
  9. Use graphics that enhance the text, add graphics to make the page "pretty" sparingly.
  10. Whenever possible, designate images to load as "Interlaced Images". This will allow all of your text to load first (because it is faster than images), and then to load the images.

Backgrounds
Backgrounds are used to enhance the page. They appear behind the text and other grpahic images. Backgrounds should be used to contribute to the page, rather than distract from it. Use subtle textures and colors.
