HP CALCULATOR (revised 8/27/97) "PANIC BUTTONS" - ON and VAR



Variables stored in HOME directory are used globally throughout the calculator. Do not work in HOME.



I. Create a new directory called "CHEM" (shows up as a bar over the name):

1. TEAL, MEMORY



2. NEW, (OBJECT) DOWN ARROW, (NAME) ALPHA, type name, ENTER (or OK), CHK, ENTER (or OK)



3. To move between directories: PURPLE, UP or TEAL, HOME



Practice: Make sub directories of CHEM called FORMULAS. Move between HOME, CHEM, FORMULAS directories.



II. Store, retrieve, delete a number:



1. Select the appropriate directory



2. (number), ENTER



3. ', ALPHA, type a name, STO



4. To retrieve press button under appropriate variable name (use NXT if needed to find it)



5. To delete a number (or equation): ', (select variable),ENTER, PURGE. For multiple deletions: {, (select all variables or equations to be deleted), ENTER, PURGE



Practice: Store B = 40. Delete B



III. Store, retrieve, delete equations:



1. Select appropriate directory



2. ', ALPHA, (type equation, be sure to use x,/), ENTER, ' , (type name of equation, don't make name same as variable in the equation, STO



3. Retrieve and delete the same way as number was done in II.



4. Lower case letters (ALPHA, PURPLE), Greek Letters (TEAL, CHARS), ECHO (or appropriate key stroke), ENTER



Practice: Store D = g/V as DEN, Q = mCT as HEAT, and

ln (P2/P1) = -H/R (1/T2 - 1/T1) as CLAUS in FORMULAS directory



IV. Using the Solver:



1. TEAL, SOLVE, select SOLVE EQUATION, OK



2. CHOOS, find equation, OK, enter values, highlight unknown, SOLVE. Press ENTER to transfer to stack if entire number can't be seen.



Practice: In DEN, find V if D is 0.78 and m is 35. (Ans: V = 44.87) Find Q is C is 4.184, m = 40, and T is 25. (Ans: Q = 4184) In CLAUS find P1 if P2 is 700, H is 40000, R is 8.314, T1 is 298, T2 is 400 (Ans: P1 = 11.4)



VII. Scientific notation:



1. TEAL, MODES, select number format, CHOOS, select scientific, OK, highlight number to right, enter number of decimal places desired, OK, OK. Calculator will now display all numbers in scientific notation.



VIII. Retrieving Constants



1. PURPLE, 3, select COLIB, select CONLI



2. Find constant, select VALUE to convert to number and UNITS to add the units.



3. -->STK to transfer to stack.



Practice: Find Avogadro Number, speed of light, Faraday constant





IX. Unit Conversions:



1. TEAL, UNITS, select a units directory.

2. Enter number into display but do not push ENTER, select starting unit, PURPLE, select unit to convert to.



PRACTICE: Convert 50 grams to amu (u) (Ans: 3.01 x 1025) Convert 10 fathoms to meter (Ans: 18.3)





X. Metric Conversions (as well as any non menu unit conversion):



1. Enter number into display but do not push ENTER, TEAL __, ALPHA, (type unit - case sensitive), ENTER, enter 0, TEAL __, ALPHA, (type unit to be converted to), +

2. Get µ from Greek Chars list.



3. Complex units can be built from units in different directories.



PRACTICE: Convert 1.21 gigawatts (GW) into milliwatts (mW). (Ans: 1.21 x 1012) Convert 0.031 cg into µg. (Ans: 310) Convert 35 J into l*atm (Ans: 0.345).





XI. Unit Calculations:



1. Number, enter unit (for mixed units: unit 1 x unit 2 - just enter unit 1 followed by unit 2 . For unit 1/unit 2 - unit 1 TEAL ,unit 2 ).



2. Repeat for next number then multiply or divide (cannot add and subtract unless units are the same).



PRACTICE: What is the answer, with units, for the following:



400 J/mol x 54 1/K = (Ans: 2634 g/mol)

8.2 J/g*K









































XII. Linear regression (finding equations of lines):



1. TEAL, STAT, FIT DATA, OK



2. CHOOS (if data already entered) or EDIT



3. Set GO --> , window size to personal preferences, NXT, -COL, -ROW to delete existing numbers



4. Enter first x,y pair. X is in first column, Y in second. Press the down arrow. Calculator now knows that array has only two columns. After last set of data, ENTER



5. Select model (usually LINEAR FIT, or BEST FIT), OK



6. PURPLE, DROP, Correlation: tells how perfect the fit is, the closer to + or - 1 the better.



7. PURPLE, SWAP, (equation: intercept+slope*X)

8. Save data the same way a single number is saved.



XII. Graphing the regression line:



1. PURPLE, STAT, PLOT, SCATR, STATL



XIII. Predicting values from the equation:



1. TEAL, STAT, FIT DATA, OK, PRED, enter X or Y, move cursor to other variable, PRED



2. Another way to do the same thing is PURPLE, STAT, FIT, enter a value for X or Y, PREDX or PREDY
