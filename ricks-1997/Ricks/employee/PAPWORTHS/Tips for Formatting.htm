Tips for Formatting Research Paper

Title Page

Center title about 3. 50 Position.
Type title in capital letters followed by your own name in lower case letters.
Space three spaces and type course, Professor's name and date, or type this information in bottom lower-hand corner.

Table of Contents

Use the dot leader command under Format/ Line/ Flush right with dot leaders.
Capitalize main headings as well as number them with Roman Numerals.
Type sub-decisions in lower case and indent five spaces.

Abstract

Keep it short.
Type title in lower case and center.

List of Illustrations

Center title and capitalize
Use dot leader command under Format/ Line

Graphics

Use bullets under Insert icon to enhance lists
Use graphics under Insert icon to insert graphics.
To apply a border to a page, use Format key/ Page/ Border

Works Cited page (MLA) or References (APA)

Title is centered.
Double space throughout and between entries.
Alphabetize according to last name of author.
End each entry with a period.

Page numbering

To suppress the page number on first page of report, open Format/ page/ suppress number on current page [WordPerfect}
To number pages, use Format/ page/ numbering
Change this setting to upper right-hand corner.

Line spacing

Use Format/ line/ spacing to change line spacing to 2.
Use a clear, basic font, such as Times New Roman, and set at 12.
