Advanced Web Authoring: CGI and PERL

General Information

Course Duration: 4 hours

Audience: Internet/intranet web site managers, NetWare 4 system integrators, WWW consultants, CNEs, CNIs, MCNEs, Novell Internet Manager candidates, Internet service providers, resellers

Prerequisites: Users should be familiar with basic web authoring techniques, as covered in the Web Authoring and Publishing courses. Knowledge of the Intranetware - NetWare 4.11 enviroment or of programming would be useful

Topics Covered

  • Introducing CGI
  • RCGI and LCGI
  • Using scripts
  • Introducing PERL
  • Converting HTML to PERL
  • Testing a PERL script
  • Enhancing existing PERL scripts

Course Aim

To familiarize the user with the Common Gateway Interface and its uses, and to introduce the PERL scripting language

Learning Objectives

After taking this course, the user should be able to

  • distinguish between static and dynamic documents
  • describe the Common Gateway Interface (CGI)
  • list common programming languages used to interface with CGI on Web servers
  • distinguish between RCGI and LCGI
  • describe how CGI scripts and applications are executed on a NetWare server
  • describe the function of PERL
  • convert an HTML document into PERL script
  • discuss the function of PERL
  • convert an HTML document into PERL
  • discuss how to identify and resolve errors in a malfuntioning PERL script
  • combine two PERL scripts
  • describe how a PERL script is used to analyze user input



Course Incorporates: Test, hands-on exercises
