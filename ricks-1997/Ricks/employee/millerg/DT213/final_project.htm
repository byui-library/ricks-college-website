Final projects for DT 213 are to be selected and completed on an individual basis, consistent with the subject matter of this course. All projects must include the development of a 3D Studio model and animation file. Each project should demonstrate some advanced aspect of 3D studio (including but not limited to Hierarchal Linking, Morphing, Space Warps, Inverse Kinematics, Dynamic Simulations, and Special Effects). In addition, each project should show evidence of many of the material creation and lighting techniques discussed in the class.

Projects should all result in a short, typed report with drawings/renderings as appropriate and a 3D Studio animation file (AVI). This report should explain in detail the process and problems you experienced in creating the finished project. It would be appropriate to cut&paste graphics directly into your report. The report length should be approximately 2 pages, typed, double-spaced. The report must also contain a 1 page outline which details the animation sequence frame by frame including camera moves, object transforms, etc. In addition, each report should include one full page color rendering of the model.

An oral presentation will also be required during the final examination period (Wednesday, April 21, 9:10-10:40). The oral presentation should present the material in the written report in addition to discussing techniques used in the creation of the animation file. The finished animation file should also be shown at this time. Presentations will be limited to 3-4 minutes in length, including questions. You are encouraged to use Corel Presentation or Microsoft Powerpoint to aid in delivering this presentation.

The first step of the project is to submit a 1 page, typed proposal defining your project. The purpose of the proposal is to avoid unpleasant surprises regarding the suitability of the project. Include in your proposal:

1) what you will do - be specific
2) how it is relevant to the course
3) an outline of your anticipated animation by frame

The proposal is due at the beginning of class on Friday, April 9, 1999. You may bring the proposal by my office earlier for review if you wish to start in advance of this date.

This project represents a significant portion of your grade (20%), and should reflect your best efforts. There is a good possibility that some of the projects in this class will be displayed in the near future on the department=s web page! In essence, this project constitutes the final examination for this class. Good Luck!
