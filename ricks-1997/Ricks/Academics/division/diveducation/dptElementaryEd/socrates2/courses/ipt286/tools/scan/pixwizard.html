Pix Wizard

Pix Wizard is a shareware program that is used to change the attributes of graphic images -- from the color depth, to size, to special masks, and file type. We use this program to change the graphics which are scanned or downloaded from a digital camera so that they can be used on the World Wide Web.

In most instances this process requires changing only 1 or two things prior to saving the file. The important item is that when you are done the image's file length (size) must be less than 40k! The steps that I recommend you use to accomplish this file size reduction are listed in priority order below. Each of these steps assumes that the graphic is open within PixWizard.

Color Reduction

In most cases the color depth of an image that has been scanned or taken with a digital camera is 16.7 million colors (32 bit). The number of colors need to be reduced to 15 or 16 bit (thousands of colors) for JPEG compliance or even less for GIF compliance. To do this:

  1. From the Edit menu, select Color Reduction.
  2. A dialog box will appear. Select 15 bit (32,768 colors) or 16 bit (65,536 colors) for JPEG or less for GIF.
  3. Click "OK"

Size

In many cases, graphics that have been scanned are too large for inclusion on a html document (unless you want a very large picture). So you may want to shrink the physical size of the graphic. This can be done using two different means: cropping or scaling.

Cropping

To crop a picture you must:

  1. Determine what is the focus or main idea of the picture.
  2. Draw a selection rectangle around that area of focus using your mouse and the leftmouse button.
  3. Once the rectangle is in place, from the Edit menu, select "Crop" or click the crop button (the scissors icon).
  4. All parts of the image that were outside of the rectangle will be cropped.

Scaling

To scale a picture:

  1. Go to the Edit menu and select "Resize." A dialog box will appear.
  2. Determine the resulting size you want the picture to be after resizing. This should be a proportion of the original. The current size is shown in the box labeled "Current Resolution." In the example shown, it is 146 high x 51 wide. If I want the picture to be 3/4 the size of the current image, then I would need to know that that would be .75 times 146 or roughly 110 high by 35 wide.

  1. To speed things up, click the "Keep Aspect Ratio" box. This will allow you to only change one number and the other one will maintain the same ratio.
  2. Change the large number to whatever number you determined in step 2 above. Be sure you change it on the same side of the "x" as it appears in the Current Resolution box. If the number you multiplied was the one on the left, change the box on the left or vice versa.
  3. Click OK (It is important that you NOT press the Enter key because of a bug in the program).
  4. The picture should shrink to whatever percentage was indicated.

Saving As...

The final step is the saving process. However, it is important that you use "Save As..." rather than Save. The reason for this is to allow you to change the file format type.

When you scanned your image or downloaded it you saved it as a bitmap image (which is a windows standard file format). However, for use on the WWW, a photograph should be saved as a JPG (pronounced jay-peg) file, and a drawn graphic should be saved as a GIF (pronounced Jiff) file format.

Using "Save as..." allows you to change the format of the file; thus, making it internet ready (if that is the intent of your use). An added benefit of changing a file to JPG format is that the file can be compressed, thus further reducing its size (remember the 40 k size limit?!)

After you have selected "Save As..." from the File menu a dialog box will appear:

  1. Give the graphic a name (be sure to remember that there should be no spaces and no capitals)
  2. Be sure that you are saving the graphic to your disk and inside the web folder that you have created.
  3. Make sure the format is appropriate for your graphic (JPEG for photos, GIF for artwork). Make the change in the "Save as type" menu. The selected file type's suffix "jpg" or "gif" should be added to the file name.
  4. Click Save.

Confirm the Save and Check the file size

  1. Minimize the Pix Wizard program window.
  2. Open your disk window and located the graphic file and visually confirm that your graphic is on your disk.
  3. Click the file icon or name once. In the bottom right hand corner of the window the file size should appear. This number must be less than 40 kb!
  4. If it is, then you can continue with other work or quit. But please be sure to check your disk for your work!
