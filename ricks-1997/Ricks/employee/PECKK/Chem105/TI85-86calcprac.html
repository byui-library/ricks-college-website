Texas Instrument 85 and 86 Calculator Practice Sheet
Unit Conversions
Convert 5.6 feet to km. (ANS = 0.0017 km)
[2nd], [CONV], [F1-LENGTH], 5.6, [F5-ft], [MORE], [F2-km], [ENTER]

Convert –5.5 oC to oF. NOTE: When converting negative temperature values, the negative number must be entered in parenthesis. You must use the negative key [(-)] to enter a negative number not the subtract key [-]. (ANS = 22 oF)
[2nd], [CONV], [F5-TEMP], (-5.5), [F1-oC], [F2-oF], [ENTER]

Constants
The TI has a number of built in constants. Find the value of Avogadro’s number, stored in the TI as Na.
(ANS = 6.02x1023)
[2nd], [CONS], [F1-BLTIN], [F1-Na], [ENTER]

Find the value of the speed of light, c. (ANS = 2.998x108 m/s)
[2nd], [CONS], [F1-BLTIN], [MORE], [MORE], [F4-c], [ENTER]

You can also store your own constants.

Store Y = 75.5.
[2nd], [CONS], [F2-EDIT], Y, [ENTER], 75.5, [EXIT]

The calculator stores the constant as it is entered.
You can access your constant by hitting [ALPPHA], Y, [ENTER] or through the CONS menu by entering the sequence: [2nd], [CONS], [F3-USER], [Function key below constant], [ENTER]

Delete the constant Y = 75.5

[2nd], [CONS], [F2-EDIT], [Function key below constant], [ENTER], [F3-DELET], [EXIT]

Store the constant, Z = 19. Delete the constant Z = 19.

Storing Equations
Store the density equation as DEN=MASS/VOL. To do this you must give the equation a name that is not a variable in the equation. Type the following in the calculator display, be sure to use [/]:
            DENSITY=DEN=MASS/VOL
When this is typed correctly, hit [ENTER]. Done will be displayed indicating that the calculator has stored the equation.

Store the heat equation as Q=SH*MASS*(TF-TI). Name the equation HEAT.
            HEAT=Q=SH*MASS*(TF-TI)
Hit [ENTER] to store the equation.

Using the Solver
The solver makes it possible to solve for an unknown variable in an equation which has been previously stored in the calculator memory.

Given that an object has a volume of 14 mL and a density of 4.5 g/mL, determine the mass of the object.
(ANS = 63 g)

[2nd], [SOLVER], [CLEAR], [2nd], [RCL], [Function key below DENSITY], [ENTER], [ENTER]
Once the equation has been entered and the variables are displayed in the solver:
1.        enter the known values for appropriate variables
2.        highlight the unknown variable with the cursor
3.        hit the [F5-SOLVE] key to solve for the variable.
