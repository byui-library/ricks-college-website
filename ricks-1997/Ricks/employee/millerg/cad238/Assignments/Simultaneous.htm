Simultaneous Equations



"Wherefore, my beloved brethren, if ye have not charity, ye are nothing, for charity never faileth. Wherefore, cleave unto charity, which is the greatest of all, for all things must fail.", Moroni 7:46.


Write a Qbasic program for solving 3 simultaneous equations using the Gauss-Seidel method as discussed in class.  Equations should be of the form:

Ax + By + Cz = D

The program should include the following:

  • Prompt the user to interactively enter the coefficients of any 3 equations
  • Use a tolerance check value of .0001
  • Check for convergence.  If the equations do not pass the convergence check, print a message of explanation and exit the program.

Use the following equations for your sample runs:

  1.    5X -  1Y +3Z =    4
        -2X + 5Y + 1Z = -2
         3X + 2Y + 7Z =   2

  2.    10X -     6Y + 1Z = 7
          3X + 15Y -  4Z = 10
          5X -    8Y -   9Z = 15
