Attention!

Recent Changes in Information Technology

 

Dear End User:

Below is a list of recent changes in the campus computing environment which will affect most users.  Please review them carefully.

 

1.       Domain Changed

When you login to the network it should now be to the domain “BYUI” not “RICKS” or “RICKS_COLLEGE” domain.

 

2.        E-Mail Changed

Novell’s “GroupWise” is being removed and Microsoft “Outlook” has been installed.  Your e-mail address is < i.e. Your old email address will work through the end of the year, but be sure to tell people sending you emails to use your new address.

 

3.        Home Directory

With the migration to Windows 2000 home directories have been set up for each user allowing them to store critical data in a secure area on a network server (approximately 250 MB per user).  The home directories are automatically backed up on a nightly basis.  They are also available for Mac and Win 95 users.

 

4.       AS/400

Access to the AS/400 was changed from “spencer.ricks.edu” to “spencer.byui.edu”.  If you use Rumba to access the AS/400, and it does not work it will need to be reconfigured.

 

5.       New One Card

The One Card system was changed to Diebold.  Everyone will need a new ID card.  The one card system will be used for copiers and some vending machines.  The card is designed to facilitate both charges (departmental use) and declining balance (personal use) usage.

 

6.       Copiers

New Savin copiers are networked to the Diebold one card system.  New copiers can also be used as network printers.

 

7.       Phonemail

A new phonemail system is in place.  Instructions are available on the IT home page on how to change your greetings and set a new password.  For questions call X2406.

 

8.       Phone Prefix

The BYU-Idaho telephone prefix has changed to “496”.   All telephone and fax (non-E-mail) extensions will remain the same.  E-mail fax extensions will need to be re-assigned by visiting www.byui.edu/fax . Details of this change are also available on the IT home page.

 

9.       Docutech

Due to the recabling of the ASB the IP address of the Docutech has changed.  If you want to send jobs to the Docutech please call your building CCS or Les Hill at the Press and they will make arrangements to have your computer set up to send to the Docutech.

 

10.    BYU-Idaho Letterhead

As departments order new BYU-I letterhead, the Press will prepare a template with the department footer in Microsoft Word or WordPerfect and e-mail it to them to use with the generic letterhead.

 

11.    TEC Room Controls

Responding to faculty input, Technology Enhanced Classroom controls have been redesigned to include an LCD panel, simplifying overall system operation.

 

If you have problems related to any of the above or your computer is not configured to the proper domain or email please contact your CCS.
