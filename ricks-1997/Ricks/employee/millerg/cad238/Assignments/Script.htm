Create a script file with slides which detail the creation of the clamp shown below.  You may use either vanilla AutoCAD or Mechanical Desktop to create the clamp:

  • Begin by detailing the creation of each of the 4 clamp parts.
  • Each part should be created in a different color.
  • Show both hiddenline and shaded versions of each completed part.
  • Show both hiddenline and shaded versions of the entire assembly - both assembled and exploded.
  • Limit delay time between slides to 2-3 seconds.
  • Use the RSCRIPT command so that the script file will automatically repeat itself.
  • Place all files (.scr, .sld) in a folder using the naming convention of your name followed by the key word "script", (i.e. "Brown Charlie script"
  • The script file must be design to run when the entire folder is placed within the "scrat" directory on the "C" drive.
