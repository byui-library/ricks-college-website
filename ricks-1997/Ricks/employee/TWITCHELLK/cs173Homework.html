General Instructions

  • Homework is graded using Netscape Navigator version 4.7 on a Windows 95/98 PC. Make sure your programs work in this environment. Using Internet Explorer to develop software is strongly discouraged.
  • CGI programming assignments shall execute using joshua.ricks.edu as the Web server.
  • All assignments except 00 shall be submitted by copying files to /home/ket/cs173/hw##/, where ## is the two-digit homework number (be sure to include leading zeros when necessary). Examples where whateverYouNamedIt is your file to be submitted and xyz99001 is your user ID)
    • cp whatever.txt /home/ket/cs173/hw02/xyz99001.txt
    • cp whatever.html /home/ket/cs173/hw02/xyz99001.html
    • cp whatever.pl /home/ket/cs173/hw02/xyz99001.pl
  • All assignments shall be submitted as ASCII text files.
  • Except for homework 08, submit only one file for each homework assignment.
  • Each file name shall include an appropriate extension (.html for HTML, .pl for Perl, and .txt for text).
  • Do not link to any files in your directories; link only to submitted files.
  • Homework shall not be submitted using e-mail.
  • Make sure your submitted program satisfies all specified requirements.
  • All programs shall include error handling and shall terminate gracefully.
  • You may not use Microsoft Front Page or any Perl modules.
  • Each line in each file, regardless of type, shall be less than 80 characters long.

05 Change Maker
75 points
     Write a CGI Perl script that accepts a non-negative integer less than or equal to 100 (e.g., 59). The input value shall be part of the URL (e.g., http://joshua.ricks.edu/.../whatever.pl?59) and will be available to your Perl script in $ENV{'QUERY_STRING'}. Assume the value entered by the user is the cost of something and calculate the change from $1 (100). Determine the least number of coins (quarters, dimes, nickels, and pennies) to be used as change. Create a plain text page containing your output. Output shall include the value input by the user and the change as quantities of quarters, dimes, nickels, and pennies. If the input was 59, the output is "The item cost 59 cents. Your change includes 1 quarter(s), 1 dime(s), 1 nickel(s), and 1 penny(ies)." You may not use any conditionals or loops. Assume user input is valid.

08 Graduation Progress Report
450 points
     Create a CGI application, consisting of one or more Perl scripts, that generates a graduation progress report for any (available) student with any (defined) major. The report shall match the format and provide the information specified in the sample output file. Please note the following:
  • the required number of credits is always 64.0
  • the total number of earned credits is calculated from classes completed with a passing grade
  • the remaining number of credits shall be greater than zero or a statement to the effect that this requirement has been satisfied
  • your graduation progress report must comply with catalog requirements except as noted
  • Math 101 and higher satisfy the mathematics general education requirement
  • you are not required to process transfer and AP credits; assume all classes are Ricks classes
  • you do not need to consider ACT and SAT scores for the math requirement
  • assume that all students are required to take four religion classes
  • some major required classes dictate which general education classes the student should take; you shall use what the major requires
  • your name shall appear on the output
     The following files are available as inputs to your CGI application. They are located at /home/ket/cs173/hw08/.
  • student transcript file(s) named ####.txt where #### represents any four digits - the first line is the student's name followed by a list of classes and grades for those classes
  • major requirements file(s) named ###.txt where ### represents any three digits - the first line is the name of the major followed by a list of required classes; a choice of classes is expressed using a pipe character (|)
  • general education requirements file named genEd.txt - each line starts with the category name and is followed by a list of classes that satisfy that category; please note that the requirements for the basic skills option has been simplified
          The interface shall allow the user to select a student and a major for that student. Use only the available students and majors. List the students and majors by name.
     The files provided in /home/ket/cs173/hw08/ are for your testing. Another set of files shall be used to grade the homework.
     Submit your completed scripts to /home/ket/cs173/hw08/userID/ where userID is your userID. Because you are submitting your homework to a directory, your are not required to name your files using your user ID. Use relative path names (everything is in your directory or in the parent directory).

Clarifications:

  1. Once a general education requirement is satisfied, no additional classes should appear in that general education section. If there are additional classes in that general education category that are required by the major, they should be listed in the "Major" row ("Classes Taken" or "Classes to Take" column). You may create an additional category (row) to list classes taken that don't fit anywhere else.
  2. You may use more specific terminology than "n/a" (e.g. "completed").
  3. You must observe the catalog rules for the sciences (general education): a student must have a minimum of eight credits in the natural sciences, with at least one physical science and one biological science class (using the list in genEd.txt).
09 Is it Valid?
125 points
     Create a single HTML form consisting of one text field and one button that allows the user to enter either
  • a complete user-defined Perl variable name (scalar, array, hash, and subroutine),
  • a social security number in the exact forms of 123-45-6789 or 123 45 6789
  • a telephone number in the exact forms of (208) 356-1938 or 208-356-1938, or
  • a time (including 8:47 AM, 0847, 1:13 PM, and 1313; note the locations of the spaces).
Using only a single regular expression for each situation, determine if the user entry is valid and inform the user of your decision (i.e., the entry is invalid or if valid, what it is). Be sure to exclude all invalid entries (i.e., anything that does not match the above specifications). Remember that an entry is also invalid if it includes extraneous data (e.g., a telephone number of 208-356-1938-123).

13 JavaScript Grades
75 points
     Create an HTML form that allows the user to enter a numeric grade, an integer between 0 and 100, inclusive. A number outside this range represents an error condition. Output on the same HTML page the corresponding letter grade using the following grading scale:
  • A - nineties and one hundred
  • B - eighties
  • C - seventies
  • D - sixties
  • F - 59 and below
If the final digit is 7-9, output a "+" (e.g., 88 is a B+).
If the final digit is 0-2, output a "-" (e.g., 61 is a D-).
There is no A+, F+, nor F-.
Be sure to provide appropriate error messages.
14 More JavaScript Grades
125 points
     Create an HTML form that allows the user to enter up to eight numeric grades (each an integer between 0 and 100, inclusive). Each numeric grade represents a percentage of a number of possible points. Use the following as the possible number of points: 100, 100, 100, 50, 50, 100, 50, and 450 (in this order). For the number of grades entered (eight or less), calculate the total number of points earned and the total number of points possible. Do not assume that the grades will be entered from first to last (i.e., there may be gaps in data entry). Output on the same HTML page the total number of points earned (do not round or truncate this value), the total number of points possible, the percentage of points earned (this should be a whole number; be sure to round), and the corresponding letter grade (using the scale specified in homework 13). Only average the grades that have been entered (wherever they have been entered); do not assume that all eight grades have been entered or that they have been entered in consecutive text fields.
