Internet and Intranet Skills: Setting up a Web Site

General Information

Course Duration: 4 hours

Audience:
IS professionals who are interested in maintaining a web site for use on the Internet or on a corporate intranet

Prerequisites: Familiarity with operating systems concepts, networks, intranets, and the Internet, or the equivalent CBT Systems curricula

Topics Covered

  • The Internet and intranets
  • Requirements for creating a web site
  • Choosing an Internet service provider
  • Hardware specification estimation
  • Hardware platform alternatives
  • Choosing web server software
  • Site configuration issues
  • Bandwidth estimation
  • Communications link alternatives
  • Hardware requirements
  • IP addressing, subnetting, and domains
  • Security and firewalls
  • Using a proxy server

Course Aim

To introduce users to the issues associated with hosting or administering a web site

Learning Objectives

After taking this course, the user should be able to

  • decide on the most appropriate web server deployment strategy for an intranet or the Internet
  • determine web server hardware and software requirements
  • select an Internet service provider
  • determine the type of communications link required
  • estimate communications bandwidth requirements
  • determine firewall and proxy server requirements



Course Incorporates: Test, hands-on exercises
