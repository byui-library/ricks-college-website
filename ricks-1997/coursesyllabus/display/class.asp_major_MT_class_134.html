Machine Tool Operation II
MAC TOOL OP II
CLASS CODE: MT 134 CREDITS:  3
DIVISION: PHYSICAL SCIENCE & ENGINEERING
DEPARTMENT: MECHANICAL ENGINEERING & TECHNOLOGY
GENERAL EDUCATION: This course does not fulfill a General Education requirement.
CATALOG DESCRIPTION: Planning and machining of metal parts to print dimensions, cutting feeds and speeds, surface finish, tool geometry, horsepower requirements, and tool materials.
DESCRIPTION: Planning and machining of metal parts to print dimensions, cutting feeds and speeds, surface finish, tool geometry, horsepower requirements and tool materials.
TOPICS: Topics
1. Turning Machines (4 class hours)
2. Vertical Milling Machines (4 class hours)
3. Horizontal Milling Machines (6 class hours)
4. Rotary Tables and Indexing Devices (2 class hours)
5. Gears and Gear Cutting (6 class hours)
6. Grinding and Abrasive Machining (4 class hours)
7. Advanced Machining (4 class hours)

Laboratory Projects:
1. Fabricate a metal hammer per design supplied. Requires cut-off saw, lathe and tooling, vertical and horizontal mills, and drill press.
2. Fabricate a arbor press per design supplied. Requires foundry equipment, lathes, mills, grinders, drills, and miscellaneous tooling.
3. CNC Project. Requires computer programming and vertical CNC mill.
4. EDM Project. Requires lathe, mills, and miscellaneous tooling.
OBJECTIVES: 1. Continued emphasis on basic machine tool operations including: milling machines, advanced lathe, grinding machines, and electrical discharge machining.
2. Foundry (Sand Casting) experience including: pattern design and gating systems.
3. Introduction to CNC Programming.
