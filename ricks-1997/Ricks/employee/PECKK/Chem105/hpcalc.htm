Hewlett Packard Calculator Practice Sheet
Unit Conversions
Convert 5.6 feet to km.  (ANS = 0.0017 km)
[TEAL], [UNITS], [LENG], 5.6, [FT], [NXT], [PURPLE], [KM]

Convert –5.5 oC to oF. (ANS = 22 oF)
[TEAL], [UNITS], [NXT], [TEMP], 5.5, [+/-], [oC], [PURPLE], [oF]

Directories
When storing constants and equations do not work in the HOME directory.
Create a CHEM directory.
[TEAL], [MEMORY], [NEW], [Go down to the name field, hold a and type CHEM], [ENTER], [CHK], [OK], [NXT] [OK]

Hit [VAR] to show directories. Be sure you are in the CHEM directory. Now create a FORMULAS directory within the CHEM directory. [TEAL], [MEMORY], [NEW], [Go down to the name field, hold a and type FORMULA], [ENTER], [CHK], [OK], [NXT], [OK]

To move between directories: [PURPLE], [UP] or [TEAL], [HOME]

Constants
The HP has a number of built in constants. Find the value of Avogadro’s number, stored in the HP as NA. (ANS = 6.02x1023)
[PURPLE], [EQ LIB], [COLIB], [CONLI], [Highlight NA], [VALUE], [QUIT]

Find the value of the speed of light, c. (ANS = 2.998x108 m/s)
[PURPLE], [EQ LIB], [COLIB], [CONLI], [Highlight c], [VALUE], [QUIT]

You can also store your own constants.

Store Y = 75.5.
Go to the appropriate directory: 75.5, [ENTER], [`], [Y], [STO]
Retrieve by pressing key below variable.

Delete Y = 75.5
Go to the directory with the constant to be deleted: [`], [select Y], [PURPLE], [PURG]

Store the constant, Z = 19. Delete the constant Z = 19.

Storing Equations
Store the density equation as DEN=MASS/VOL. To do this you must give the equation a name that is not a variable in the equation. Be sure you are working in an appropriate directory. Key-in the following:
1.        [`], DEN=MASS/VOL, [ENTER]
2.        [`], DENSITY, [STO]
An equation can be deleted just as a constant is deleted.

Using the Solver
The solver makes it possible to solve for an unknown variable in an equation that has been previously stored in the calculator memory.

Given that an object has a volume of 14 mL and a density of 4.5 g/mL, determine the mass of the object. (ANS=63g)

[TEAL], [SOLVE], select solve equation and hit [OK], [CHOOS], select DENSITY and hit [OK], enter values for known variables, move cursor to unknown variable field, [SOLVE]

Pressing [ENTER] will display value in stack.
