Understanding and Applying Internet Concepts: Connecting to the Net

General Information

Course Duration: 4 hours

Audience:
Internet service providers, IS personnel, system integrators, resellers, WWW consultants, CNEs, CNIs, MCNEs, support personnel, network administrators

Prerequisites:
The course Understanding and Applying Internet Concepts: The Basics

Topics Covered

  • Getting started
  • Internet addressing
  • Registering a domain name
  • Setting up the environment
  • Connectivity
  • Setting up e-mail
  • Firewalls
  • Virus protection
  • ISPs

Course Aim

To show how to configure and connect an organization's network to the Internet

Learning Objectives

After taking this course, the user should be able to

  • outline the main considerations when connecting a network to the Internet
  • list the types of connection an Internet service provider (ISP) can provide
  • describe how to upgrade an organization's internal e-mail system to accommodate Internet e-mail
  • outline how to set up a secure Internet presence
  • list what needs to be considered when selecting an ISP



Course Incorporates: Test, hands-on exercises
