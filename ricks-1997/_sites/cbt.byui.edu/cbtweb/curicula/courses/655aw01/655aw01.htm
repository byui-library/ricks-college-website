Advanced Web Authoring: SSI

General Information

Course Duration: 4 hours

Audience: Internet/intranet web site managers, NetWare 4 system integrators, WWW consultants, CNEs, CNIs, MCNEs, Novell Internet Manager candidates, network administrators, resellers

Prerequisites: Users should be familiar with basic web authoring techniques, as covered in the Web Authoring and Publishing courses. Knowledge of the IntranetWare - NetWare 4.11 environment or of programming would be useful

Topics Covered

  • About SSI
  • Preparing to use SSI
  • General syntax
  • The include command
  • Other NCSA SSI commands
  • Using NetWare Web server SSI commands
  • Other SSI considerations

Course Aim

To enable the user to recognize and use Server Side Include (SSI) commands and NetWare Web server-specific SSI commands

Learning Objectives

After taking this course, the user should be able to

  • include dynamic information in a browser document
  • enable SSI on a NetWare Web server
  • describe the syntax of SSI commands
  • use the include command
  • describe the echo, flastmod, fsize, and config SSI commands
  • discuss the SSI commands that are supported only by the NetWare Web server
  • explain why the exec command cannot be used on a NetWare Web server



Course Incorporates: Test, hands-on exercises
