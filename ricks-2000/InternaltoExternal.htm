Physical to Virtual Campus

Ricks College, like most large organizations, until now has had an internal web server that has served the function of an Intranet.  An Intranet provides information that resides behind the firewall so that it cannot be viewed worldwide.   Today’s campus is no longer confined to the traditional physical boundaries, but has several locations, often hundreds of miles from the home campus.  With students being expected to utilize on-line courses and resources, we are really creating a virtual campus, instead of a physical one.  Faculty and employees in general are in greater need today than ever before to access resources from locations other than the physical campus.  With this change in our paradigm we are making modifications to our web server configuration that will accommodate these requirements.

Protection of Confidential Information

To restrict access to confidential information, which previously resided on Intranet web pages behind the firewall, we have added authentication to these web pages.  Authentication requires the entry of username and password, which all students and employees are issued.

Implementation Schedule

Due to a hardware failure, and unavailability of replacement parts, this change was implemented sooner than expected and without notice to our user community.  We apologize for any inconvenience this may have caused.

Transition from Internal to External Home Page

All links that were displayed on the Internal Home Page are now included on either the External Home Page or the Employee Page.  Every effort has been made to verify that all links are accounted for.  We will continue to utilize new technology to improve the efficiency of navigating the web site.

Instructions for Changing Browser Default Home Page Settings

If your browser was previously set to view the Internal Home Page, web.ricks.edu, as the default, you should change the address to the External Home page, www.ricks.edu. We will now give you instructions for both Microsoft Internet Explorer and Netscape.

Microsoft Internet Explorer:

  1. Go to the Ricks College Home Page by typing www.ricks.edu in the Address text box..
  2. On the Tools menu, click Internet Options.
  3. Click the General tab.
  4. In the Home page area, click Use Current.

Netscape:

  1. Open the Ricks College Home Page by typing www.ricks.edu in the Location text box.
  2. From the Edit Menu, choose Preferences.
  3. Click the Navigator category.
  4. Click Use Current Page to select the current page as your home page.
