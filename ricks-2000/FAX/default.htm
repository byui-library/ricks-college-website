L		 Faxing from GroupWise
Faxing from your desktop is as easy as sending an email message. 

1) Open a new message window in GroupWise.

2) In the "To:" line, type Fax:"name"@8faxnumber[callingcard#]. For example, if you wanted to fax your Christmas list to Santa and his fax number was 359-4709, you would type the following on the "To:" line: Fax:"Santa Claus"@83594709.
Since this is a local number, we do not need to include a calling card number. If we did, type it immediately following the fax number; there is no need to separate them with commas or brackets. The brackets indicate that the information is optional.  It is an off campus number so we need to preceed the fax number with the number 8. This phone number with the number eight would be as if you were calling from your office phone on campus or a manual fax machine.  

The text inside the quotes will appear on the cover page on the "To:" line.

3)Type something in the subject line. This text will appear on the subject line on the fax cover page.

4)Type something in the body of the message. This is optional. This text will appear as a note on the cover page of the fax.

Figure 1. New Message Window in GroupWise.

5)Attach any files you may want to send. These can be plain text, Wordperfect or Microsoft Word documents. You can attach spreadsheets, images, etc. See below for a current list of supported file types. 

Attachments:   Attachments are automatically converted to fax images and sent as if they were scanned through a conventional fax machine. In other words, if you have a 9 page Wordperfect document, the receiving fax machine will receive a cover sheet followed by the 9 page Wordperfect document. 

Our Christmas list example does not include any attachments. Since I typed my wish list in the message box, only the cover page will be sent with my list on the cover page. Figure 2 illustrates the resulting fax page.

Figure 2. Resulting Fax from Figure 1.

You can omit the quoted name on the "To:" line. This results in the fax number being placed on the "To:" line of the cover page. The message body is also optional. The following two figures illustrate this. The attached text file contains the identical Christmas list appearing in the message body in Figure 1.
