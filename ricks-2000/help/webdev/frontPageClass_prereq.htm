Definitions and Terms that must be understood and practiced.

  • Minimize a program/window - To reduce a window to an icon on your screen.  This helps reduce clutter when you have several windows open at the same time.  In Windows, you minimize a window by clicking on its Minimize button, the minus symbol in the upper right hand corner of the program window.  The program will then minimize to the task bar.

  • Maximize a program/window - To enlarge a window to fill your whole screen.  In Windows, you maximze a window by clicking on its Maximize button, the square button in the upper right hand corner of an opened program.

  • Map a drive - Assigning a share to an assigned letter.

  • Browser - Short for Web browser, a software application used to locate and display Web pages. The two most popular browsers are Netscape Navigator and Microsoft Internet Explorer. Both of these are graphical browsers, which means that they can display graphics as well as text. In addition, most modern browsers can present multimedia information, including sound and video, though they require plug-ins for some formats.

  • Right-click - When using a mouse, click the button on the right.

  • User name - A unique name for each user of computer services which can be accessed by several persons.  The user names assigned here at Ricks College are usually the last name followed by the first initial of your first name.  Example: Name = John Smith; Username = smithj

  • Email address - Your email address is your user name followed by @ricks.edu.  Example: Name = John Smith; Username = smithj; Email Addres = smithj@ricks.edu
