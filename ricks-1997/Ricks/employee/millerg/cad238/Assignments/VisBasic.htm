Using VisualBasic with AutoCAD

 

"Those who insist upon too much explaining before obeying are insisting on a complete map instead of trusting in a beckoning Lord. Such individuals would discard the map anyway because they would not be willing to follow it; it would seem too simple, too direct.", Neal A. Maxwell.


Write a VisualBasic program to create a parametric, 3-D wireframe version of the tapered nose clamp (see previous lab)

All required input should be entered through the dialog box, including the dimensions of the clamp, origin point, and an alphanumeric part number.  The dialog box should also include an isometric picture of the clamp, complete with labeled dimensions. 

The dialog box should include 2 command buttons:  Draw and Cancel.   The program should be designed such that if the user cancels instead of selecting Draw the part is not drawn.

Include error checking such that negative numbers are not permitted for the clamp dimensions.  Also the Draw button should be dimmed (not enabled) until all required input has been entered.

As always, use good programming techniques:

  • Include header documentation (pgm name, purpose, etc.) in the main UserForm module.
  • Include comments in all modules as appropriate
  • Use good, concise, well-documented code
