2. Understanding the PowerPoint Interface

[ Contents ] [ Previous ] [ Next ]

Successfully creating a new slide will drop the user into the main interface for PowerPoint. The interface contains many features common to the Graphical User Interface environment including Title Bars, Menu Bars, Navigation buttons, Toolbars with Icons, Slide bars, and more. The interface also contains features that are specific to PowerPoint such as the View Selectors (at the bottom left of the screen) and Slide Layout Selectors (top right of the screen).

The view selectors indicate the current view of the data entered into the presentation. The data can be viewed one slide at a time (the first selection on the left), as an outline in text format (second selection), thumbnails of all of the slides on each page (third selection), in a notes format with a single slide at the top and notes for the slide at the bottom (fourth selection), and finally as a full screen presentation (fifth selection). The type of view chosen will depend on the task being performed.

The Slide Layout Selectors are used to create new slides (the first button on the left), edit the layout of the current slide (second button), or to change the style (template) of the current slide (third button) or view the presentation in Black and White mode (as it would appear if printed).
