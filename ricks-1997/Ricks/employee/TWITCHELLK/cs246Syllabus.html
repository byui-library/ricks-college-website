CS246 - Advanced Object Oriented Programming
Syllabus

Continuation of study of object-oriented programming. Advanced software development and object oriented design. Design and code larger programs. Utilizes the Java language.

The objectives of this course are to teach

  1. Requirements specification and design prior to writing code.
  2. Object oriented software design.
  3. Advanced skills in object oriented programming.
  4. Skills to prepare students to adapt as computer science and software engineering continue to evolve.

After completing this course, the student should be able to

  1. Learn new design technologies and new languages.
  2. Develop and analyze design alternatives.
  3. Apply problem solving techniques to programming.
  4. Describe the concepts relevant to the object oriented approach to programming.
  5. Know and understand debugging strategies for larger programs.
  6. Program using the Java language.

Prerequisite

  • CS 235 (Foundations of Computer Science I)

Required Texts

  • Using UML: Software Engineering with Objects and Components by Stevens & Pooley
  • The Java Tutorial: A Practical Guide for Programmers, available at http://java.sun.com/docs/books/tutorial/

Optional Texts

  • Thinking in Java by Eckel, available at any of the mirror sites listed at http://www.EckelObjects.com/DownloadSites/
  • Introduction to Programming Using Java by Eck, available at http://math.hws.edu/javanotes/
