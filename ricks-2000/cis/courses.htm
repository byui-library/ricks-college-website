CIS Courses

CIS 140* Microcomputer Applications 3 credits
Introduction to the use of microcomputers in business including HTML, windows and windows applications of spreadsheets and database programs.
CIS 201 Management Information Systems 3 credits
Prerequisite: CIS 140 or consent of instructor
Introduction to information systems; use of information technology to solve business problems. Hands-on use of spreadsheet, database, HTML and telecommunications software in a business context (BYU transfer).
CIS 202 Visual Programming Languages 4 credits
Application of event driven and structured programming techniques to develop information system software. Emphasis is on program logic and user interface design. Using a visual language, students will design, code, test, and debug programs.
CIS 235 Internet Techniques 3 credits
Prerequisite: CIS 140 or consent of instructor
Study of concepts, strategies, tools and ethical issues involved in the use of the Internet. Focuses on design and construction of Home Pages including HTML. Includes Web Server management concepts and development of Internet and Intranet web sites and servers.
CIS 240 Networking 3 credits
Principles of networking designed to provide an understanding of data communication protocols, transmission systems, media, software and hardware interfacing. NT Network operating system covered.
CIS 256 Systems Analysis and Design 3 credits
Examination of systems development life cycle emphasizing tools and methods of analysis and general design including investigation, study, definition, systems specification / selection, modeling and normalization.
CIS 257 AS/400 Concepts 2 credits
Introduction to the following IBM AS/400 computer topics: Control Language, files, DFU and Query.
CIS 258 RPG IV Programming Languages 4 credits
Introduction tot he RPG IV programming language, including programming concepts, design, data structures, report programming, screen design, subfiles and interactive programming.
CIS 265 CASE Tools 3 credits
An introduction to the use of computer-aided systems engineering tools (CASE). CASE tools are used in the analysis and design of computer information systems. CASE tools will be used to develop several small introductory information systems.
CIS 286 Job Search 1 credit
A career planning, job search and interview preparation course. This course should be taken during the Sophomore year.
* Gives G.E. credit in the Basic Skill Option
