Access Test Review Criteria

To be successful with this application's exam you should be able to:

  • Switch views between the design and datasheet view and work within both views
  • Understand fields, records, tables and databases and be able to use each appropriately
  • Understand different field types and be able to specify the appropriate type in design view
  • Understand, build and use queries, forms and reports
  • Establish and use relationships between tables, including relationships using Lookups!
  • Develop simple queries
  • Design and Modify reports
  • Build reports based on queries and tables
