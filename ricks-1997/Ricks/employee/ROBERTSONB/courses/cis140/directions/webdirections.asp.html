Page 8 Step 2 – type the file name in all lower case characters. Follow this naming convention (all lower case) when naming any folder or file that will be used with the World Wide Web.
Page 9 Step 1 – Keep in mind that not all web browsers display pages the same. Word will use the browser that is “registered” with the Operating System as the primary web browser. If that browser is Netscape Navigator the page may format strangely. If it does, go to Word, Select the Tools menu, and then Options. When the options menu opens, click the General tab and click the Web Options button. Then click the General tab. In the middle of the dialog box change the setting to Internet Explorer 4.0 and Netscape Navigator 4.0. Click OK twice. Then try previewing the page again. If the problems persist it may be that you are using an old browser. If this is the case you should probably consider updating your web browser.

Page 18 Microsoft calls locations within a document a Bookmark. The rest of the world calls these location markers “Anchors.” Just be aware that they are the same thing as you encounter these terms.

Submitting your work

    1. Open the web folder inside the CIS140 Assignments folder. Check to insure that there are two subfolders: jackson_electronics and webcase.

    3. Open the jackson_electronics folder and check that there are 4 pages, 1 picture and 2 folders inside.
    4. Navigate back to where you can rename the "web" folder.
    5. Rename the "web" folder (inside the CIS140 Assignments folder), to LastF.Section.web. (Remember the naming rules covered in the syllabus).
    6. Use Windows Explorer to navigate so that your CIS140 Assignments folder is visible and expanded in for folder list, and that you have also expanded the J drive, Robertsonb folder, so that the dropbox folder is also visible.
    7. Right-mouse drag the LastF.Section.Web folder from the H drive to the dropbox in the J drive. From the Options menu select copy here...
    8. When a warning dialog box appears indicating that you will not be able to retrieve the folder once it has been copied click "OK". Do this each time it appears (it appears with every folder).
    9. When it is done copying, the assignment has been submitted.
    10. After copying the folder, send me an e-mail telling me that you have done so. The subject line should be: Web Assignment Submitted.
