General Instructions

  • Each homework assignment, except 00, shall include a work log.
  • Homework is graded using Netscape Navigator version 4.77 on a Windows 2000 PC. Make sure your Web pages and programs work in this environment. Using other browsers to develop software is strongly discouraged!
  • CGI programming assignments shall execute using joshua.byui.edu as the Web server.
  • All assignments except 00, 01, and 14 shall be submitted by copying files to /home/twitchellk/cs273/hw##/, where ## is the two-digit homework number (be sure to include leading zeros when necessary). It is best to use submit273t to submit your homework. Examples where whateverYouNamedIt is your file to be submitted and xyz99001 is your user ID):
    • submit273t whatever.txt
    • submit273t whatever.html
    • submit273t whatever.pl
    You may also copy your files to the homework directory. Examples:
    • cp whatever.txt /home/twitchellk/cs273/hw02/xyz99001.txt
    • cp whatever.html /home/twitchellk/cs273/hw02/xyz99001.html
    • cp whatever.pl /home/twitchellk/cs273/hw02/xyz99001.pl
  • All assignments shall be submitted as ASCII text files. An assignment that is resubmitted because the file is not an ASCII text file is subject to late penalties.
  • Do not use absolute path names in your CGI (Perl) scripts; always use relative path names.
  • Except for homework 12, submit only one file for each homework assignment.
  • Each file name shall include an appropriate extension (.html for HTML, .pl for Perl, and .txt for text).
  • Do not link to any files in your directories; link only to submitted files.
  • Homework shall not be submitted using e-mail.
  • Make sure your submitted program satisfies all specified requirements.
  • All programs shall include error handling, shall execute without run-time errors, and shall terminate gracefully.
  • Each line in each file, regardless of type, shall be less than 80 characters long (except for long URLs).
  • You may not use Microsoft Front Page or any Perl modules.
  • Web pages shall not contain any of the following:
    • Frames
    • Blinking text
    • Non-terminating animated GIFs
    • Scrolling text/marquees
    • Non-standard link colors

100 points

  2. What has been done to solve this problem?

07 Change Maker
75 points
     Write a CGI Perl script that accepts a non-negative integer less than or equal to 100 (e.g., 59). The input value shall be part of the URL (e.g., http://joshua.byui.edu/cgi-bin/.../whatever.pl?59) and will be available to your Perl script in $ENV{'QUERY_STRING'} (use this as you would a variable).

Output shall include the value input by the user and the change as quantities of quarters, dimes, nickels, and pennies. If the input was 59, the output is "The item cost 59 cents. Your change includes 1 quarter(s), 1 dime(s), 1 nickel(s), and 1 penny(ies)."
     You may not use any conditionals or loops. Assume user input is valid.

12 Graduation Progress Report
400 points
     Create a CGI application, consisting of one or more Perl scripts, that generates a graduation progress report for any (available) student with any (defined) major. The report shall match the format and provide the information specified in the sample output file. Please note the following:
  • The required number of credits is always 64.0.
  • The total number of earned credits is calculated from classes completed with a passing grade (exclude "F" and "W").
  • The remaining number of credits shall be non-negative.
  • You are not required to process incompletes.
  • A repeated class simply replaces the previous grade. No additional credits are earned for a repeated class.
  • You are not required to process transfer and AP credits; assume all classes are BYU-I classes.
  • You do not need to consider ACT and SAT scores for the math requirement.
  • Assume that all students are required to take four religion classes.
  • Some major required classes dictate which general education classes the student should take; use what the major requires (i.e., major requirements supercede general education requirements).
  • There shall be a minimum of four credits of physical science and a minimum of four credits of biological science.
  • Your name shall appear on the output.
  • You may use more specific terminology than "n/a" (e.g. "completed").
  • You may list specific classes rather than specify "see catalog."
  • Use the title in the general education file (genEd.txt) for the title of the general education category in the output.
  • Once a general education requirement is satisfied, no additional classes should appear in that general education section. If there are additional classes in that general education category that are required by the major, they should be listed in the "Major" row ("Classes Taken" or "Classes to Take" column).
  • Create an additional category (row) to list classes taken that don't fit anywhere else.
     The following files are available as inputs to your CGI application. They are located at /home/twitchellk/cs273/hw12/.
  • student transcript file(s) named ####.txt where #### represents any four digits - the first line is the student's name followed by a list of classes and grades for those classes
  • major requirements file(s) named ###.txt where ### represents any three digits - the first line is the name of the major followed by a list of required classes; a choice of classes is expressed using a pipe character (|)
  • general education requirements file named genEd.txt - each line starts with the category name and is followed by a list of classes that satisfy that category; please note that the requirements for the basic skills option has been simplified
  • classes file specifying the course number followed by the minimum and maximum number of credits for that course; always use the maximum number of credits possible
     The interface shall allow the user to select a student and a major for that student. Use only the available students and majors. List the students and majors by name.
     The files provided in /home/twitchellk/cs273/hw12/ are for your testing. Another set of files shall be used to grade the homework.
     Submit your completed scripts to /home/twitchellk/cs273/hw12/yourUserID/ where yourUserID is your userID. Because you are submitting your homework to a directory, you are not required to name your files using your user ID. Use relative path names (everything is in your directory or in the parent directory).
