Selecting a New Slide Layout

Up to this point we have concentrated on adding and editing objects on a single slide. Most presentations contain more than a single slide, therefore, we need to know how to add more slides. New slides are added to the presentation using the "New Slide" button located at the top right of the screen and shown below.


Selecting a New Slide Layout

Pressing the New Slide button immediately provides you with a screen where you are provided with options for the layout of the new slide. This screen is the same as the screen that is displayed when the "Layout" button is pressed. The screen is shown below:



The slide layout can be changed even after data has been entered into the slide (some data may be lost of course depending on the new selection). If templates were available for slides, these templates could be accessed using the "Apply Design" button located to the right of the "Slide Layout" button. The Apply Design button is shown below:

It is important to note that new slides are always inserted directly after the current slides Fortunately, the position that slides are displayed in can be changed using the slide sorter (described in the next section)

Deleting a Slide

To delete a slide, display the slide you want to delete and then select "Delete Slide" from the "Edit" Menu. If you made a mistake, you can use the Undo option to bring back the slide.
