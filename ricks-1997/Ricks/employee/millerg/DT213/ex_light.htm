DT 213 Exercise
Lighting

The purpose of this exercise is to help you gain familiarity with the different lighting types and effects available in 3D Studio Max. For this exercise you will be using a model that has been previously created and changing only the lighting. The file is located on the network on Engr on Jupiter with a path of \classes\dt213\lighting scene.max.

Create each rendering described below as separate jpg files at a resolution of 640x480. Use simple names such as Problem n for each rendering. Place the renderings and the model (with the lighting and settings from Problem 10) inside a folder in the DropBox when complete using the key word of Light before your name.

Begin by creating a rendering using 3D Studio Max's default lighting on the scene. You may want to save this as Problem 0 and use for comparison. This problem does not need to be handed in.

Problem 1 Set the global ambient lighting value to 100.
Problem 2 Reset to default. Place one omni light near Light Location box. Set the multiplier to 1.5.
Problem 3 Add shadow casting to Problem 2.
Problem 4 Reset to default. Place one target spotlight starting at the Light Location box with the other end at the leaning torus (torus03). Set the multiplier to 1.5.
Problem 5 Add shadow casting to Problem 5.
Problem 6 Change hot spot to 35.0 with settings from Problem 6.
Problem 7 Repeat Problem 6 using Race-Traced Shadows.
Problem 8 Return to Shadow Maps and change falloff to 40.0 and spotlight shape to rectangular with settings from Problem 7.
Problem 9 Reset to default. Place one target directional light starting at the Light Location box with the other end at the leaning torus (torus03). Set the following parameters: multiplier 1.5; cast shadows; hot spot 80; falloff 90; color green & blue to 0 (leaving only red)
Problem 10 Reset to default. Light the room such that the 2 pictures are spotlighted using volumetric lights as discussed in class. Change their color to a slight yellow. Use appropriate level of ambient lighting and omni lights to remove dark corners from the scene. The omni light should be placed above near the center of the room and set to cast shadows. Turn down the intensity on the lighting as necessary so that the focus is on the pictures. Try to make the lighting in the scene appear as close to the rendering shown as possible.
