DT 213 Exercise
Materials

The purpose of this exercise is to help you gain familiarity with the creation of basic materials and settings available in 3D Studio Max. For this exercise you will be using a model that has been previously created and adding materials to the scene. The file is located on the network on Engr on >Jupiter= with a path of \classes\dt213\materials scene.max. This exercise also will involve the creation of a brand new materials library.

After creating each material and adding them to the scene as described, create a rendering (jpg format) at a resolution of 640x480. Place the rendering, the material library and the model inside a folder in the DropBox when complete using the key word of Material before your name.
