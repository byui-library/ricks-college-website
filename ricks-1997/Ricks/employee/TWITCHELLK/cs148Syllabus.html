CS148 - Computer Science Review
Syllabus

Review of CS 144 and CS 145 concepts for those who have not been taking Computer Science classes for an extended period of time.

The objectives of this course are to

  1. reintroduce students to the computer lab
  2. provide students an opportunity to renew programming skills
  3. review concepts required for later classes (particularly CS 235, Data Structures)

After completing this course, the student should be back in the "mode" of taking Computer Science classes and completing the programming assignments for those classes.

Lecture topics:

  • Mechanics
    • Introduction and overview
    • mechanics: computer labs, Linux, C++, and Java
  • Procedural Paradigm
    • identifiers; reserved words; data types; ASCII; constants; variables; arrays
    • strings, simple I/O
    • Böhm and Jacopini structures; single-entry, single-exit; structured programming
    • pointers
    • pointers: dynamic memory allocation
    • functions, pass by value & reference, recursion
  • Object Oriented Paradigm
    • coupling, cohesion, abstraction, encapsulation
    • composition, inheritance, polymorphism
    • class definition, access modifiers
    • constructors, destructors
    • copy constructors
    • operator overloading
  • Software Engineering
    • design
    • algorithm development, debugging

Prerequisites: CS 144 (or CS 165 or CS 170 or CS 205 or CS 206) and CS 145 (or CS 171 or CS 246)

Text: none (students supply their own reference material)
