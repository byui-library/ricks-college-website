DT 213 Exercise
Standard Primitives

The purpose of this exercise is to help you gain familiarity with each of the 10 standard primitives available for object creation in 3D Studio Max. These include Box, Sphere, Cylinder, Torus, Teapot, Cone, GeoSphere, Tube Pyramid, and Prism.

Create the scene depicted below using only these primitives (i.e., do not use shapes and modifiers such as extrude, taper, etc.). Position the objects approximately as shown in the scene using transform modifiers of move, rotate, and scale as appropriate.

Note the following construction requirements:

Create the table top using a cylinder and material of your choice.

Create the table legs out of boxes and material of your choice. After creating one box, copy it to create the remaining three.

Create a pot using the teapot command and material of your choice. Note the absence of the handle and spout.

Create the golf balls in a glass class using the geosphere and tube commands. Adjust the geosphere parameters so that the texture resembles that of a golf ball. Adjust the material parameters of the tube such that is transluscent.

Create the stacking toy using the torus, cone, sphere, and prism commands. Create the base out of a prism and material of your choice. Create the pedestal out of a cone with a sphere on the top. The cone and sphere should be of the same materials and sized such that they appear to be one object. Create the rings using the torus command. Use different color plastic materials for each ring. After creating the first ring, use the scale and copy command to create additional rings.

Balance the stacking toy on top of 3 pyramids using the pyramid command and material of your choice.

Add a couple of omni lights and a spotlight to illuminate the scene. Set the spotlight to cast shadows. Select a light colored background.
