This is the process to connect your computer to the server (joseph) that holds all the web pages. You have a folder on joseph, called a share, which we will connect to. This folder will appear as a drive letter on your computer.

Map Network Drive
  1. Begin by clicking on the Start Menu button.

  2. Click on Programs.

  3. From programs, click on Windows Explorer.

  4. From the menu click on Tools, then click on Map Network Drive...

  5. In the Drive: box, choose a drive. (Note: The next drive available is selected automatically.)

  6. In the Path: box type \\joseph\ Followed by your username (example: doej ) and a $ dollar sign.

  7. Click OK.

    You've succesfully mapped a network drive to you share on Joseph.
