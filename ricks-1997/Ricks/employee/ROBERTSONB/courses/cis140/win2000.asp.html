Windows 2000 Assignment

This Assignment is done after finishing all tutorial work in the text.
1. Open Windows Explorer (Right mouse click the Start button, Select Explore).
2. Navigate to the H drive, Win2000 folder on the left side of the Explorer.
3. Click the Win2000 folder once. Be sure all files within it are visible in the files window on the right.
4. Do a Window Print Screen (Alt + Print Scrn). [This produces a graphic image of the window in RAM memory.]
5. Open Word 2000. Type your name and Section at the top of the new document. Press Return twice. From the Edit menu select Paste.
6. A picture of the Explorer Window should appear. Make sure all files are visible in the picture.
7. Save the word document as lastf.section.win2000.doc to your CIS140 Assignments folder on the (H) drive. ["last" means your last name, "f" is your first initial, "section" is the number of the section in which you are enrolled].
8. Create an E-mail message and attach the above document to it.
9. Send it to me at robertsonb@ricks.edu.
10. You should receive a confirmation receipt from my email account.
