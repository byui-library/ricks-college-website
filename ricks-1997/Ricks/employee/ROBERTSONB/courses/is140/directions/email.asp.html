Adding E-mail Attachments

These directions assume that you are using Microsoft Outlook web client accessed through the BYU-Idaho web site.

1. Using an application create and save the document that will be the attachment to a disk or harddrive.

2. Open the Outlook web client by opening your web browser (Internet Explorer or Netscape Navigator).

3. In the Address or Location bar type " http://mail.byui.edu/MailPage.html " and press the Enter key

4. Read and follow the directions for logging into the system.

5. Click the Logon button, then type your username and password in the appropriate location (note: you must type the domain name before your own username in the Username text field, e.g. students/ada01001) and press Enter.

6. Create a new email message.

7. Click the paper clip icon ( a screen tip will appear "Add Attachment") at the top of the message window.

8. A "Web Page Dialog" window will appear. Click the "Browse" button and browse to the location where the file to be attached is saved.

9. Double-click the file to be attached. You will return to the "Web Page Dialog" window and the full path to the attachment is shown to the left of the Browse button.

10. Click the "Attach" button. The file name should appear below the Attach area that shows the name of the file(s) currently attached to the email message.

11. The attach more than 1 file to the email, repeat steps 8 - 10.

12. When you are done, click the "Close" text at the top of the "Web Page Dialog" window.

13. You will return to the email message and see that the attached file(s) displayed below the subject line text box.

14. Complete the email and click "Send" when finished. Note: The actual attached file will not be sent, only a copy of it.
