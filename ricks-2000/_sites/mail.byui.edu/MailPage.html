The Ricks College email system is now running on a Microsoft Exchange server. This should provide you with added features and stability.
To login, you will be presented with a login window:
For Students:
  • Enter "students\username" on the User Name line.
  • Enter your password on the Password line.
         (Your 1 to 5 digit PIN number by default)
    		•
    For Employees:
  • Enter "byui\username" on the User Name line.
  • Enter your password on the Password line.
         (Your network password and email password are the same.)
