ITC Tools

The ITC has technology which will enable you to:

  • Edit and create film projects.
  • Convert audio files to mp3, wav, midi, etc.
  • Import and export video to and from a DV.
  • Capture VHS clips and convert them into Quicktime or AVI movies.
  • Edit digital movies.
  • Create Adobe PDF files.
  • Scan and retouch old photographs for family history albums.
  • Scan 35mm slides and save them as jpegs, gifs, or bitmaps.
  • Create dynamic, engaging Web sites and Web pages.
  • Spruce up your PowerPoint/Corel Presentations.
  • Create digital animations.
  • Take Digital pictures.
  • Scan a hard copy of an article and save it as a Word or WordPerfect document.
  • Create animations using Macromedia Flash.

The software available in the ITC includes:

  • iMovie (Easy film editing)
  • Microsoft Office 2000 (PowerPoint, Word, Excel, Frontpage)
  • Adobe Photoshop 5.0/6.0 (Graphic creation/editing program)
  • Adobe Imageready 3.0 (Add effects to Web Pages created in Photoshop 6.0)
  • Adobe GoLive! 4.0/5.0 (Web page author tool)
  • Adobe Illustrator 8.0/9.0 (High-end graphic creation tool)
  • Macromedia Flash 4.0 (Creates dynamic, interactive animations for Web Pages)
  • Adaptec Toast 4.0 (Create data or audio CD-ROMs)
  • Adobe Premeire 5.1 (Digital Movie editing tool)
  • Final Cut Pro (Digital Movie editing tool)
  • Debabelizer Pro (Graphics Conversion tool)
  • Adobe PageMaker 6.5 (Document Creation tool)
  • Adobe Dimensions 3.0 (3D graphics creation tool)
  • OmniPage Pro 8.0 (Text scanning tool)
