This is the process to create an Email form in FrontPage 2000.

Creating an Email form
  1. Create a Html Form

  2. Edit the Form Field Properties
    If you have a Form Element for the user to type in there email address, change the Name of the Form Element to sender
    Change the Name of the Submit button to Submit
    For Each Form Element change the Name So it describes the type of information the Form Element will have
    Warning make sure you DON'T USE SPACES in the Name

    Also you can change the Value of a Form Element in the example below we changed the Value
    of Blue to be Yes instead of the default
    Example Form

    Your Name:

    Are you Blue?

    		Example Email

    Name: Papa Smurf

    Blue: Yes
    Name, and Blue are the names of the Form Elements from the Form
    Papa Smurf is the Value of Name
    Yes is the Value> of Blue
  3. Open Notepad and Paste the following lines of code there
    <form method = "POST" action ="https://web.archive.org/web/2001/http://www.byui.edu/AspUtilities/email/email.asp">
    <input type = "hidden" name ="recipient" value = "recipientEmailAddress">
    <input type = "hidden" name ="subject" value = "subjectline">
    <input type = "hidden" name ="message" value = "message">
  4. Edit the code you just pasted so that recipientEmailAddress, subjectline, and message have the values you want

    recipientEmailAddress is who the email is going to be sent to and needs to be a ricks college email address
    Faculty Email Example
    <input type = "hidden" name ="recipient" value = "smithj@ricks.edu">
    Student Email Example
    <input type = "hidden" name ="recipient" value = "aaa00001@NEPTUNE.ricks.edu">

    subjectline This will be the subject line of the email
    Example <input type = "hidden" name ="subject" value = "Math 101 Survey">

    message is the message you want displayed to the user after they submit the form
    Example <input type = "hidden" name ="message" value = "Thank you for filling out this survey">
  5. Click on the HTML TAB so you can start editing the HTML code

    Look in the Html Code for several lines that look like those below
    Warning If you are not using FrontPage they might look differently

    <form method="POST" action="--WEBBOT-SELF--">
    <!--webbot bot="SaveResults" U-File="fpweb:///_private/form_results.txt"
    S-Format="TEXT/CSV" S-Label-Fields="TRUE" -->

    You want to delete these lines of code, and replace them with the four lines of code you edited in Notepad from step #3 and step #4
