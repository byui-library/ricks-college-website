DT 213 Exercise
Creating Complex Objects Using Boolean Operators

The purpose of this exercise is to help you gain familiarity with using boolean operators to create complex objects easily. All of the objects pictured below were created using only the standard primitives of Box, Sphere, and Cylinder, with the use of Boolean Operators Union, Subtract, and Intersect.

Create all the objects inside a single 3D Studio Max model. Place the model in the DropBox when complete using the key word of Boolean before your name. Since there is only 1 file with this assignment do not place it inside a folder.
