Welcome to the PowerPoint Lecture Page. I have created these lectures to help you better understand the concepts we are discussing in class. I hope you will find them not only helpful, but also enjoyable. Please note, that in order to view these lectures, you need to have Microsoft PowerPoint Viewer installed on your computer. It is a free plug-in, which you can download from the Microsoft's site here. Make sure you download the correct player. You can find all the information on that site. If you are using Windows 95/ 98, download time for the player will be about 45 minutes, using a 28.8 modem. The file size is just under 3 Mb. If you already have Microsoft Office or Microsoft PowerPoint Presentations 97 installed on your computer, then you should be able to view these lectures without any additional downloads. Enjoy!
