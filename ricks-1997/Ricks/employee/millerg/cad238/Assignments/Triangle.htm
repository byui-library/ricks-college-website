CAD 238
Triangle

 

"...Those who can bend their knees in prayer do not feel they are stooping when they bend to help a neighbor in need.", Neal A. Maxwell.


Write an AutoLISP program that creates a triangle.  The program should prompt the user for 3 points.  The program should show rubberbanding lines between points 1 & 2 and points 2 & 3.  Create the triangle using the line command.  Use the C:FunctionName syntax to make the function available as an AutoCAD Command.
