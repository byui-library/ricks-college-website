Misdemeanors

Carrying Concealed Weapon-----$ Fine and/or jail time set by Madison County Magistrate Judge
When carrying a firearm in your vehicle it must be unloaded.
Idaho Criminal Code 18-3302

Computer Crime---------$ Fine and/or jail time set by Madison County Magistrate Judge
Computer Crime can be committed in various ways in the state of Idaho. If you access or use or even attempt to access or use a computer without authorization you have commited computer crime. If a file is renamed, taken or read without authorization, computer crime is commited. and of course, if  a program is altered, destroyed or damaged, or the computer is used to commit theft or fraud,  Computer Crime is comitted.
Idaho Criminal Code 18-2202

Criminal Trespass of a Dwelling-----$ Fine and/or jail time set by Madison County Magistrate Judge
To meet the criteria of this crime, you must enter a person's dorm room or apartment after they have told you not to. Or remain there after they have told you to leave. You do not need to commit any other crime to get arrested.
Idaho Criminal Code 18-7011

Drinking Alcoholic Beverage in Public-----$ Fine and/or jail time set by Madison County Magistrate Judge
You may not consume any alcoholic beverage on Ricks College Campus or in public in the city of  Rexburg.. This includes: buildings, roads, sidewalks, parking lots, driveways/alleys, etc.
Rexburg City Ordinance

Disturbing the Peace-----$  Fine and/or Jail time set by Madison County Magistrate Judge
This can consist of many things. Arguing with a Police Officer in a threatening manner. Fighting. Using obscene language in public in front of children. Disturbing any event with obnoxious or threatening behavior. Basically creating an offensive or threatening environment anywhere you are at.
Idaho Criminal Code 18-6409

Dog Running at Large-----$ Fine and/or Jail time set by Madison County Magistrate Judge
Dogs need to be on a leash at all times on campus.
Rexburg City Ordinance

DUI-----$ Fine and/or Jail time set by Madison County Magistrate Judge
Having immediate physical control over a vehicle, while impaired by alcohol.
If you are drinking and are close to your car, give your keys to a friend who is not drinking, this will help avoid any misunderstanding between you and a Police Officer!!
Idaho Criminal Code 18-8004

Resisiting and Obstructing Officers-----$ Fine and/or Jail time set by Madison County Magistrate Judge
Every person who wilfully resists, delays or obstructs any public officer, in the discharge, or attempt to discharge of any duty of his office or who  knowingly gives a false report. In other words...You must give your correct name, date of birth, and address to an Officer upon request.
Idaho Criminal Code 18-705

Illegal Fireworks-----$ Fine and/or Jail time set by Madison County Magistrate Judge
Basically anything that explodes or shoots high in the the air.
Rexburg City Ordinance.

Littering-----$ Fine and/or Jail time set by Madison County Magistrate Judge
Idaho Criminal Code 18-7031

Minor in Possession of Alcohol-----$ Fine and/or Jail time set by Madison County Magistrate Judge
You. must be 21 to consume or possess alcohol in Idaho.
Idaho Criminal Code 23-949

Minor in Possession Tobacco-----$ Fine and/or Jail time set by Madison County Magistrate Judge
Must be 18 to possess Tobacco in Idaho
Idaho Criminal Code 39-5703(2)
.
Open Container of Alcohol in Vehicle-----$ Fine and/or Jail time set by Madison County Magistrate Judge
Having any container of alcohol in your vehicle that has been opened. Includes cans, bottles, box (of wine), etc. Once one container is open, everyone in vehicle can be arrested, you don't need to be drinking to be arrested.
Idaho Criminal Code 23-505

Possession of Dangerous Weapon at a School-----$ Fine and/or Jail time set by Madison County Magistrate Judge
A person may not possess any dangerous weapon or firearm at a place that he/she has reason to believe is a school. This Includes Ricks College.
Idaho Criminal Code 18-3302D

Possession of Drug Paraphernalia-----$ Fine and/or Jail time set by Madison County Magistrate Judge
It is unlawful for any person to use, or to possess with intent to use, drug paraphernalia to plant, propagate, cultivate, grow...or otherwise introduce a controlled substance into the human body...
Idaho Criminal Code 37-2732(c)3

Possession of Marijuana-----$ Fine and/or Jail time set by Madison County Magistrate Judge
All you have to do for this one is be in the same room/car, as someone using it, and fail to report the activity to Law Enforcement. You don't have to touch or smoke it.
Idaho Criminal Code  37-2732(c)3

Theft of Services-----$ Fine and/or Jail time set by Madison County Magistrate Judge
Using any service without paying; Sneaking in to any event (athletic, dance), parking in a lot without paying, etc.
Idaho Criminal Code18-2403(5)(a)

Throwing Missiles -----$ Fine and/or Jail time set by Madison County Magistrate Judge
Throwing anything at a person, car or item  without obtaining the permission of the party.
Rexburg City Ordinance
