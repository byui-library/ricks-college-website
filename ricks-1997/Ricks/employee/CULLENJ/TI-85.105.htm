TI-85 CALCULATOR (revised 9/5/97) "PANIC" button = EXIT





I. Store, retrieve, delete a number:



1. To store: (enter number), STO, (name), ENTER



2. To retrieve: 2nd , RCL, (name), ENTER or 2nd, VARS, REAL, (find variable), ENTER, (ENTER)



3. To delete: 2nd, MEM, DELETE, REAL (or MORE to find EQ if you want to delete an equation), (find variable or equation), ENTER, EXIT.



WARNING: Each time you hit ENTER, you will delete what the cursor highlights!



Practice: Store B = 40, multiply 3B, delete B



II. Store an equation:



1. (Name of equation - use ALPHA to produce letters), = ,



2. (type equation - use more than one letter for each variable, don't use same name for variable and equation name, if you want lower case letters (2nd , ALPHA) Greek Letters (2nd , CHAR, GREEK, then use appropriate key)), ENTER.



Practice: Store the following using contractions of the variable names if you want. Just be sure that the equation name and a variable name are not the same.

DENSITY = MASS/VOLUME as DENS, HEAT = MASS*SPECIFICHEAT*T as HET,

ln (P2/P1) = -H/R (1/T2 - 1/T1) as CLAUS



III. Using the Solver:



1. 2nd , SOLVER, CLEAR



2. 2nd , RCL, (select equation, use MORE if necessary to find), ENTER, ENTER



3. (enter known values, highlight unknown), SOLVE.



4. Sometimes it is necessary to give the variable you are solving for an initial quess before you solve. This is always necessary if the variable to be solved for is in the denominator of a fraction.







Practice: Find VOLUME if DENSITY is 0.78 and MASS is 35. (Ans: VOLUME = 44.87) Find HEAT if T is 25, SPECIFICHEAT is 4.18, MASS is 40. (Ans: HEAT = 4180) Find T1 if P2 is 700, H is 40000, R is 8.314, P1 is 100, T2 is 400. (Ans: T1 = 344)





IV. Scientific notation:



1. 2nd , MODES, select SCI, ENTER, EXIT. Calculator will now display all numbers in scientific notation.

IX. Editing Equations



1. Type name of equation, =, 2nd RCL, type name of equation, ENTER

2. Edit equation then press ENTER



Practice: Edit your density equation by changing the name of one of the variables.



X. Linear Regression (finding equations of lines):



1. STAT, EDIT



2. If data has never been entered before name X variable, ENTER, name Y variable, ENTER



3. If data has been entered before, select X variable, ENTER, select y variable ENTER



4. If you want to clear the data stored, press CLRxy, enter new x,y pairs



5. YELLOW, CALC, ENTER, ENTER, LINR (for straight line)



6. a = intercept of line

b = slope of line

corr = correlation (the closer to + or - 1 the better the straight line

n = number of data points



XI. Predicting values from the calculated line:



1. YELLOW FCST, enter either x or y value, move cursor to other variable, SOLVE

XII. Graphing regression line:



1. GRAPH, RANGE, set xMin to 0 or value close to smallest x value, set xMax to maximum x value, do the same for yMin and yMax, EXIT



2. STAT, DRAW, SCAT (plots the data points), DRREG (draws the regression line), CLRDRW (clears the graph), CLEAR (lets the full graph be seen)



Practice: Plot the graph of the regression line.
