PageManager Desktop Information

Assumptions:

The directions on this page assume that you have already used PageManager to scan an image and that that image is now on the PageManager desktop.

Directions:

Once an image has been scanned it is moved to the PageManager desktop -- don't confuse this with the computer's desktop; they are not the same. The PageManager desktop looks similar to the image below:

[Sorry the graphic is being remodeled]

 

  1. In most cases once an image has been scanned, it will open into a thumbnail image on the desktop.
  2. Double-click on the thumbnail image on the desktop to open it.
    It will open in an edit window
  3. Select Save as… from the File menu
  4. Save the image to your disk (put the disk in if needed)
  • If you are using a floppy, go to drive A:
  • If you are using a zip, go to drive E:
  1. Make sure the file type is .bmp (Bitmap)
  2. Name to file appropriately (following WWW naming rules) and add the suffix .bmp.
  3. Click OK
    • The file is now saved to your disk.
  4. Once you have saved the image to your disk, confirm that it is on your disk.
  • Minimize the PageManager window
  • Double-click the appropriate shortcut on the desktop to open your storage disk (removable or floppy)
  • Visually confirm that the file is on your disk
  1. When you have confirmed that the file is on your disk then delete it from the PageManager desktop by:
  • Clicking the PageManager window button on the Task Bar
  • Single clicking on your image (A red border will appear around the image indicating that it is selected)
  • Then select "Delete Image" from the Edit menu.
  1. Quit the program, shut all open windows
  2. · Eject your disk and take your picture from the scanner
