Introduction

There are a number of basic skills that everyone who uses a computer should understand how to do, among these skills are:

  • Creating new folders and documents
  • Naming folders and documents properly
  • Determining object properties
  • Determining what operating system your computer uses
  • Determining the amount of random access memory (RAM) your computer has installed
  • Determining the storage capacity of your hard drives and other storage devices
  • Copying, pasting and cutting objects and elements from one location to another
  • Using the the left and right mouse buttons

The following exercise in intended to introduce or review each of the above elements in order to assure that all students have some experience with each of these basic skills. Keep in mind that there are usually two or even three ways to do each of these skills. However, the exercises below are intended to introduce you to only one of these ways in order to avoid confusion.

Creating a New Folder

In this exercise you will create a new folder and name it IS 140 Assignments on your H: drive.

  1. Locate the Student H icon on the desktop, double-click it using the left mouse button on your mouse.
  2. When the window opens, move your mouse anywhere in the canvas of the window that is white and is not already occupied by an icon or text.
  3. Click the right mouse button. An Options menu appears. Move the mouse cursor to the New menu item and then slide it to the Folder submenu item and left mouse click.
  4. A new folder icon appears and it is labeled "New Folder", (Note: the text is inverted) type the name of the folder, "IS 140 Assignments" (omit the quote marks). Press the Enter key.

Creating and Naming New Objects

In this exercise you will create new documents and folders. Typically a new document is created by opening an application, constructing the document and saving it to a specific location using a meaningful name. However, using Windows 2000 a new document can be created without opening the application. It cannot be edited, but it can be created using this process.

  1. In the same window that you created the IS 140 Assignments folder, again move the mouse cursor to white space in the window canvas.
  2. Right mouse click. The Options menu appears. Move the mouse cursor to the New menu. Leave the mouse there while you look at the New submenu which appears. (Note that at the top you have the option to create a new folder or shortcut, but below these two options are listed applications. The applications list will vary by the software which is installed on your computer. There should at least be text documents listed.. On our machines you should also have Microsoft Word and Microsoft Excel. There may be others in addition.)
  3. Click Text document from the New submenu. Once the new document has appeared name it lastf.section.text.txt (the .txt extension is needed by Windows 2000 to identify the file as a text document).
  4. Repeat step 3 two more times; however, select Microsoft Word and Microsoft Excel respectively. Name the Word document, lastf.section.word.doc and the Excel document, lastf.section.excel.xls.
  5. Create another new folder and press Enter. The folder retains the New Folder name. However, we wanted to name it "Windows Exercises".
  6. Right mouse click the folder and click Rename from the options menu. The text is highlighted and you can now change the name to Windows Exercises. Press Enter when done typing the new name. (Note: folders do not have file name extensions, but files must have! Each file type has an extension that associates it with an application on the computer. Without the extension the file cannot be identified and will not easily open on the computer and will be shown with a standard windows icon rather than the application icon. When using the Options menu to rename files, be sure to include the extension preceded by a period at the end of the file name. Common extension types used in our class include:
    • .doc - Microsoft Word document
    • .xls - Microsoft Excel document
    • .txt - windows text document (most commonly used by Notepad)
    • .htm or .html - Hypertext Markup Language document (used on the World Wide Web)

Determining Object Properties

Every object on a computer (e.g. folder, file, graphic, movie) has properties. A property describes the object in terms of size, date created, date modified, owner, type as well as other descriptors. It is important to be able to examine properties to know about an object.

  1. Right click the text document that you created. From the Options menu, left-click the Properties option.
  2. A Properties dialog box appears. Note the size of the file on disk and the Opens with application name. Also, note that across the top of the dialog window are tabs. Click the Summary tab and click the Author line. Type your own name in the author line.
  3. Click the OK button to close the dialog box. Then double-click using the left mouse button the icon for the text document. In the document, type the disk size of the file, the Opens with application name and your own name each on a new line. Close the document and save the changes.
  4. Now, reexamine the properties of the text file and note the changes. Also, note that the time and date stamp for the Modified and Accessed lines have changed.
  5. Repeat this process for the Word and Excel documents. Remember to open the document and record the same 3 pieces of information: Disk Size, Opens with application name and your name, each on a new line. Be sure to save the file when closing it.

Moving, Cutting, Copying and Pasting Objects

In this exercise you will use each of the means indicated in the above subtitle to change an object's location. Keep in mind that while we are using files and folders, these skills also pertain to text and other objects within documents.

  1. In the same window that you have used to create the three files and two folders, locate the text file.
  2. Click and hold the left mouse button on the file icon and drag it to the Windows Exercises folder. When the folder's icon darkens, release the mouse button. The file will Move into the folder. Open the folder to insure that it has moved. Return to the previous window by clicking the Up icon (on the toolbar at the top of the window, a folder with a up arrow on it).
  3. Locate the Word file. Click and hold the right mouse button on the file icon and drag it to the Windows Exercises folder. When the folder's icon darkens, release the mouse button. This time an Options menu appears. Click the "Copy here" option. The file is copied to the Windows Exercises folder and the original remains in the IS 140 Assignments folder window. Open the folder to insure that it has copied. Return to the previous window by clicking the Up icon.
  4. Locate the Word file again and click it using the right mouse button. From the Options menu click, Rename. Change the name so that "word" is replaced with "original". It should now be named lastf.section.original.doc. Move it to the Windows Exercises folder.
  5. Locate the Excel file. Right click it and select (click) Cut from the Options menu. Open the Windows Exercises folder. In the white canvas area right mouse click and select Paste from the Options menu. The file should appear. Return to the previous window by clicking the Up icon.
  6. Right mouse click the Windows Exercises folder and view its Properties. Note the size and contains lines in the properties dialog box. Viewing a folder's properties box is the only way to know its size!
  7. Move the Windows Exercises folder so that it is inside the IS140 Assignments folder.

Operating Systems, RAM and Storage

In this exercise you will examine the properties of the computer to identify the key properties of Operating System, RAM and capacity of your hard drives. Just as you did with the files and folders to examine their properties, the same can be done with the computer. On the desktop there is an icon whose default name is My Computer. On machines outside of the lab setting, this name may be changed.

  1. Locate the My Computer icon.
  2. Open the properties dialog box of the My Computer icon (If you have forgotten how, review the Determining Object Properties section).
  3. The Properties window opens. Note that there are five tabs across the top of the window. Make sure the General tab is the front.
  4. The General tab has three submenus with associated information. 1) The System menu tells you what operating system the computer is using. The Registered to menu indicates who registered the operating system at the time of installation. Finally, the Computer menu indicates the type of processor installed, its compatibility type and the amount of RAM (memory) installed.
  5. Write down the Operating System and service pack installed and the amount of RAM. Close the Properties window.
  6. Double click the My Computer icon. A window opens that shows all of the devices attached to the computer. Local hard drives (there may be more than one) are usually designated as drives C & D. Locate the C drive and open its Properties window.
  7. Make sure the General Tab is in front. Note the type of information being shown includes a label (if any) for the drive, the file system being used, the total size, the amount used, the amount free as well as other information. DO NOT CHANGE ANY SETTING ON ANY TAB!
  8. Record the file system type, the total size and the total free on the drive on the same paper where you recorded the operating and RAM information.
  9. Close the C drive properties window.
  10. Open the Windows Exercises folder. Create a new Text document, name it lastf.section.computer-info.txt. Open the file and record each of the property datum you recorded to this new file. Type your own name on the first line and use appropriate line titles and record each data point on its own line. Close and save the document.

Submitting the Exercise

For this exercise you are going to capture a window image of your work and send me a file with the image and the lastf.section.computer-info.txt document. The steps below should guide you through this process.

  1. Close all windows.
  2. Right-click the Start button on your computer (bottom left corner of the screen on the task bar).
  3. Select Explore from the Options menu.
  4. Scroll up until you see a small minus symbol to the left of the C: drive icon. Click the minus symbol. The list of objects associated with the C drive should disappear leaving only a list of the devices attached to your computer. If any other drives have minus symbols, click them as well until all you are left with is a list of devices with each of them having a plus sign to their left.
  5. Locate the plus sign to the left of your H: drive. Click it once.
  6. The H: drive should expand, showing you a list of all folders in the drive.
  7. Locate the IS 140 Assignments folder on the left side (below the H: drive icon) and click the plus sign to its left once.
  8. The Windows Exercises folder should appear beneath it and slightly indented to the right. Click it once.
  9. In the right window should be icons for each of the files you created and placed into this folder during this exercise. Double check to insure that they are all there: two text documents, two word documents and one excel document.
  10. Change the window so that all folders on the left are visible, as well as files on the right. If the window fills the screen then resize the window so that it does not.
    • Click the restore down button (middle one of the three in the top right corner of the window), then do a manual resize by placing the mouse cursor on the right edge of the window (until the cursor turns to a double headed arrow). Hold down the left mouse button and drag the window edge to the left). Do the same to the bottom edge until the window is about six inches square. Again make sure all folders are visible in the left pane and all files are visible in the right.
  11. When you are sure everything is viewable and sized correctly, hold down the ALT key and press the Print Scrn key on the function key row (top row of keys on the keyboard, third button from the right).
  12. This takes a picture of the active window. However, it does not place it physically anywhere. It is stored temporarily in RAM. You must paste it into a document in order to view it.
  13. Move to the right pane of the window (where the other documents are stored). Create a new Word document. Name it lastf.section.win2000.doc. Open it.
  14. Type your name on the first line, your section number on the second and press Enter twice.
  15. Right mouse click the page and select Paste from the Option menu.
  16. The picture should appear on the page.
  17. Close the document and save the changes.
  18. Open the same email client that you used for the Email assignment and create a new e-mail message addressed to Br. Robertson. Add my email address from your address book or contact list. Add an appropriate subject line to the email message.
  19. Attach two documents to the message: lastf.section.computer-info.txt and lastf.section.win2000.doc.
  20. Send the message and the assignment has been submitted.
