Note: The nested AND function allows you to evaluate multiple criteria as part of the IF function. For example the formula found in step 2, when compared with Figure A1-10 would read, “If the values in cells B2 equals FT and the value of cell d2 is greater than or equal to 1 then multiply the value of cell E2 by 3 percent. If the values in cells B2 and D2 do not meet the criteria then return a zero.”
A1.12

Note: The nested IF function allows you to which of two criteria are true and return a different result for each, or if neither are true to return a different result for the false statement. The formula in Step 2, in English, would read “If the value of cell C2 is “F” then return 5000. But if the value of cell C2 is I return 4000. If the value of cell C2 is not F nor I then return 0.”
