Machine Tool Operation
MACH TOOL OPER
CLASS CODE: MT 131 CREDITS:  3
DIVISION: PHYSICAL SCIENCE & ENGINEERING
DEPARTMENT: MECHANICAL ENGINEERING & TECHNOLOGY
GENERAL EDUCATION: This course does not fulfill a General Education requirement.
CATALOG DESCRIPTION: Operating principles of basic machine tools. Major emphasis on metal lathe operation and techniques and acquaintance with precision measuring instruments.
DESCRIPTION: Operating principles of basic machine tools. Major emphasis is on metal lathe operation and techniques and acquaintance with precision measuring instruments.
TOPICS: TOPICS: (and number of class hours for each topic)
1. Introduction and Safety (2 class hours)
2. Turning Machines Lathes)and Tooling (3 class hours)
3. Cutting Tools and Chip Formation (3 class hours)
4. Cutting Speeds, Feedrates, and Infeeds (2 class hours)
5. Basic Lathe Operations (Facing, Centering, Turning between centers)(3 class hours)
6. Dimensional Measurement (Micrometers, Vernier Calipers, Comparison Measuring, Gage Blocks, Angular Measuring) (4 class hours)
7. Fits and Tolerances and Geometric Tolerancing (3 class hours)
8. Drilling Tools and Operations (3 class hours)
9. Threads (Nomenclature, Calculation, and Cutting with Single Point Tool)(3 class hours)
10. Casting (1 class hour)
11. Tapers (Calculations and Producing) (2 class hours)
12. Materials (Ferrous and Nonferrous)(2 class hours)
13. Heat Treating Ferrous Materials (2 class hours)

LABORATORY PROJECTS:
1. Lathe familiarization and safety
2. Tool grinding
3. Facing, centering, and turning exercise
4. Second turning exercise (reduced tolerances)
5. Layout, drilling, sawing, and finishing C-Clamp
6. Threading (practice, graded thread, and C-Clamp bolt)
7. Tapers
8. Casting
9. BoringMajor emphasis is on metal lathe operation and techniques and acquaintance with precision measuring instruments.
OBJECTIVES: To introduce student to safe operation of basic machine tools such as lathes, vertical milling machines, and drilling machines.
To acquaint student with machining variables, setup, and machining of basic geometric shapes such as cylinders, tapers, and threads.
To acquaint student with the mechanism of chip formation, tool selection, and tool geometry.
