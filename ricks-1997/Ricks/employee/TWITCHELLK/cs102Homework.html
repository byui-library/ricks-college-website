General Instructions

  • Homework is graded using Netscape Navigator version 4.77 on a Windows 2000 PC. Make sure your Web pages and programs work in this environment. Using other browsers to develop software is strongly discouraged!
  • All HTML and JavaScript assignments (homeworks 06, 08, 09, 10, 11, 12, 13, 14, 15, and 16) shall be submitted by copying ASCII text files to /home/twitchellk/cs102/hw##/, where ## is the two-digit homework number (be sure to include leading zeros when necessary). It is best to use submit102 to submit your homework. However, you may also use the Linux copy command (cp) to copy your files to the homework directory. Examples where whateverYouNamedIt is your file to be submitted and xyz99001 is your user ID):
    • submit102 whatever.html
    • cp whatever.html /home/twitchellk/cs102/hw##/xyz99001.html
  • All other assignments (homeworks 01, 02, 03, 04, 05, and 07) shall be submitted on paper. If you submit your homework after I leave for the day, you do so at your own risk. I am not responsible for homework assignments I do not receive.
  • Homework shall not be submitted using e-mail.
  • Make sure your submitted homework satisfies all specified requirements (with exactness, see Alma 57:21).
  • Microsoft FrontPage shall not be used to create HTML files.

10 Count the Coins
20 points
     Create a form that provides a text field for the user to input an integer. Label it with "cents." Include a push button labeled "Number of Coins." Include four text fields labeled "quarters," "dimes," "nickels," and "pennies." When the user enters an integer in the "cents" text field and clicks on the "Number of Coins" button, calculate the least number of quarters, dimes, nickels, and pennies to total the amount specified by the user. Hint: use Math.floor to truncate values and modulus (%) to obtain the remainder. Output these values in the appropriate text fields.
11 Grades
20 points

Include another text field labeled "letter grade." When the user enters an integer in the "numeric grade" text field and clicks on the "go figure" button, determine and output the associated letter grade in the "letter grade" text field.
