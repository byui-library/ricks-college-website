Recent Changes from Telecommunications Services

 

PREFIX

 

The new telephone prefix of 496 for BYU-Idaho was activated Monday, August 27, replacing the 356 prefix.  All extension numbers will remain the same. 

 

FAX

 

356 fax numbers will simply change to 496.

359 fax numbers will no longer be valid. Please request reassignment of a new 496 fax extension through the web access for employees.

 

3000-4000 EXTENSION

 

If in the past you have been using extension numbers in the 3000 and 4000 range, please know these will require a 79 preceding the number.  This group of extensions is in the process of being switched over.  Eventually all 3000 and 4000 numbers will be changed; in the meantime if you run into problems try the other version.

 

PHONEMAIL

 

The new Phonemail number is 794999.  For those of you who haven't recorded your personal message yet, you will use 794999 instead of the 4991 number we gave you earlier.

 

Everyone will also have to re-program their message waiting button.  You can do this by doing the following:

 

If you have a staspd (station speed) button push staspd button twice + 0 + 794999.

 

If you don't have a station speed button do the following : # # 3 + 0 + 794999.

 

You can then access phonemail just by pushing your msgwt button.

 

Your phones will be answered by the new system, so if you haven't recorded your personal message please do so.
