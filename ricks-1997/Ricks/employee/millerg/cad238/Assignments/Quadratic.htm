CAD 238
Quadratic Equation


"What a man continually thinks about determines his actions in times of opportunity and stress.", David O. McKay.


Write a Qbasic program for finding the roots of a quadratic equation such that

ax2 + bx + c = 0

There are 3 possible outcomes:

  1.     2 roots (both unique)
  2.     1 root (actually 2 duplicate roots)
  3.     complex or imaginary roots

Your program should be able to handle all three classes of problems.  Output should include which type of problem (i.e. 2 root, 1 root, imaginary roots) in addition to the actual results.  Output should be descriptive and easy to understand.  The program should also include an option to allow it to easily be repeated for subsequent cases.

Use the following equations for your sample runs:

  1. 3x2 + 5x - 2 =0
  2. 4x2 - 4x + 1 = 0
  3. x2 - 6x + 25 =0
