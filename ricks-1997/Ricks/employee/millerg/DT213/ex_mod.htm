DT 213 Exercise
Basic Modifiers

 

The purpose of this exercise is to help you gain familiarity with the most commonly used modifiers: Bend, Taper, and Twist. In this exercise you will be required to change the gizmo center and limit the effect of a modifier in many of the objects. Some of the problems will also require you to use a combination of modifiers to achieve the desired results.

Create all shapes inside a single 3D Studio Max model. Place the model in the DropBox when complete using the following naming convention: Mod Your Name. Since there is only 1 file with this assignment there is no need to place it inside a folder.
