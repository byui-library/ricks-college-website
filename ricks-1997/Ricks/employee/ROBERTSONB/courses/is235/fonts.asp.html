Font Families and example font faces

The five web font famalies included in stylesheet definiations are:

Serif (characters with embellishments)

The default font face is:

Times (Mac)
Times New Roman (PC)

Other examples of this font-family include:

Bodoni, Garamond, Minion Web, ITC Stone Serif, MS Georgia, Bitstream Cyberbit

Sans-serif (characters without embellishment)

The default font face is:

Arial (PC)
Helvetica (Mac)

Other examples of this font-family include:

MS Trebuchet, ITC Avant Garde Gothic, MS Verdana, Univers, Futura, ITC Stone Sans, Gill Sans, Akzidenz Grotesk

Cursive (flowing, joined and/or stylized characters) *

The default font face is:

Comic Sans (PC)
Zapf-Chancery (Mac)

Other examples of this font-family include:

Caflisch Script, Adobe Poetica, Sanvito, Ex Ponto, Snell Roundhand


Fantasy (decorative, while still containing representations of characters - not symbolic) *

The default font face is:

Ransom (Mac)
Old English (PC)

Other examples of this font-family include:

Alpha Geometrique, Critter, Cottonwood, FB Reactor, Studz

Monospace (fixed width characters)

The default font face is:

Courier (Mac and PC)

Other examples of this font-family include:

MS Courier New, Prestige, Everson Mono



For a FULL explanation of CSS font use and standards visit the Fonts Standards page of the W3C website.

* Not supported by Netscape 4.x or lower browsers
