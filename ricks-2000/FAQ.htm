Why does Ricks College screen all Internet sites and block some?

Mainly for ethical and business reasons. The amount of Internet traffic that can be handled is relatively small and we want to make sure that traffic is in keeping with the business purposes of the college. Visiting of inappropriate sites not only creates traffic that is useless to the college, but also poses an ethical dilemma.

What is the Ricks College Internet Filter?

Every Internet site visited from on campus goes through a computer system that checks the site being visited to make sure it is not in its database of sites to be blocked. Every site, whether visited or blocked, is logged. The logs are monitored for inappropriate activity.

How are sites blocked?

Sites are blocked by their Internet Address or "IP Address". Site contents are not searched to see if any inappropriate material is contained, nor are words filtered. There is a database of sites that is created manually by a company. We automatically get the latest copy of the database every night.

What should be done if a site is not blocked that should be?

Anyone can send an e-mail to suggest@netpartners.com requesting a review of any site for categorization and inclusion in the filter database. Include in the e-mail the full path to the site you want reviewed.

What should be done if a site is blocked that shouldn't be?

Anyone can send an e-mail to suggest@netpartners.com requesting a review of any site for categorization and exclusion from the filter database. Include in the e-mail the full path to the site you want reviewed. Local help can be obtained by e-mailing noc@ricks.edu or by calling extension 2050.

Why can't all inappropriate sites be successfully blocked?

There is no way of knowing whether a site contains material that Ricks College wishes to block by only knowing the address of the site. The site must be viewed to determine whether it is appropriate or not. New sites are created on the Internet frequently, which may or may not contain material that should be blocked, and so the filter software vendor is constantly updating the list on the database to reflect these new sites.

Is Internet Access logged by Ricks College computers?

Yes, every failed or successful attempt to access an Internet Site from the Ricks College network is logged by the Filter software. This log file is reviewed and disciplinary action is taken for repeated access to or repeated unsuccessful attempts at access inappropriate sites.
