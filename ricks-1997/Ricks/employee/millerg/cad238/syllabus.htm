Description:

A study of advanced Computer Aided Design applications using AutoCAD and 3D Studio Max software. Topics include advanced solids modeling, drawing layout, menu & toolbar creation, slides, script files, linetype & crosshatching creating, attributes, system variables, macros, automation, dialog boxes, AutoLisp, Visual Basic programming, advanced animation and creation of special effects.

Prerequisites:         CAD 234 or CAD 172 or equivalent, CAD 213 recommended

Course Objectives:

Upon completion of this course, each student should be able to do the following:

·         Customize AutoCAD for a specific user environment including Utilize AutoCAD's mode settings, drawing setup functions, and other aids to create drawings

·         Demonstrate proficiency in use of AutoLisp and Visual Basic in an AutoCAD environment.

·         Demonstrate proficiency in creation of computer-generated, photo-realistic renderings using 3D Studio.

·         Demonstrate proficiency in the creation of full-motion animations of simple mechanical assemblies using 3D Studio.
