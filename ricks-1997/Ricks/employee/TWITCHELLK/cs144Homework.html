General Instructions

  • All assignments except 00 shall be submitted by copying files to /home/twitchellk/cs144/hw##/, where ## is the two-digit homework number (be sure to include leading zeros when necessary). It is best to use submit144 to submit your homework. However, you may also use the Linux copy command (cp) to copy your files to the homework directory. Examples where whateverYouNamedIt is your file to be submitted and xyz99001 is your user ID):
    • submit144 whatever.cpp
    • cp whatever.cpp /home/twitchellk/cs144/hw##/xyz99001.cpp
  • All assignments shall be submitted as ASCII text files (i.e. submit the source code, not the executable).
  • C++ source code files shall be submitted using the .cpp extension.
  • Homework shall not be submitted using e-mail.
  • Make sure your submitted program satisfies all specified requirements.
  • Output shall exactly match the examples, with the only variation being output values that are calculated from input values.
  • All programs shall include error handling and shall terminate gracefully.
  • Whenever the homework specifies that the program is to loop until the user specifies to quit, the input from the user shall be the word "quit". Nothing more and nothing less.
  • For all character input, you must allow for the input of any case, including mixed case.
  • You may not use the following in your programs:
    • the system function
    • any time function
    • the strpbrk and strspn functions or anything like unto them
      note: you may use strchr
  • Use C++ I/O (e.g., cout); do not use C I/O (e.g., printf).
  • Each program shall compile and execute using ROM 272 (Linux) lab computers.
  • Source code shall conform to style guidelines.
  • Each line in each submitted file shall be less than 80 characters long.
  • Placing a portion of your source code in a header (.h) file is discouraged.

02 Temperature
50 points
     Prompt the user to enter a floating point number (e.g., 98.6). After reading the number from the user, assume the number is Celsius and convert the value to Fahrenheit using the provided formula. Output the original number followed by C and the converted temperature followed by F. Output both values to exactly one decimal place. Next, assume the original number is Fahrenheit and convert the value to Celsius using the provided formula. Note: neither prompt the user for input nor read input from the user a second time. Output the original number followed by F and the converted temperature followed by C. Output both values to exactly one decimal place. Assume user input is valid.
     Examples (user input is shown in bold):
  • Please enter a floating point number: 98.6
    98.6C is 209.5F
    98.6F is 37.0C
  • Please enter a floating point number: -40
    -40.0C is -40.0F
    -40.0F is -40.0C
03 Change Maker

After reading the number from the user, calculate the amount of change from $1 (100), assuming that the user input represents the cost of an item in cents. The program determines the least number quarters, dimes, nickels, and pennies to be used as change. Output "The item costs ### cents." where ### is the value input by the user. Follow this with the change specified as quantities of quarters, dimes, nickels, and pennies. You may not use any selection or iteration structures. Assume user input is valid.
     Examples (user input is shown in bold):
  • Enter the cost of an item in whole cents (0-100): 59
    The item costs 59 cents. Your change is 1 quarter(s), 1 dime(s), 1 nickel(s), and 1 penny(ies).
  • Enter the cost of an item in whole cents (0-100): 5
    The item costs 5 cents. Your change is 3 quarter(s), 2 dime(s), 0 nickel(s), and 0 penny(ies).
