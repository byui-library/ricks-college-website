HOME DECOR SEWING
HOME DECOR SEW
CLASS CODE: HFED 221 CREDITS:  2 FEE:  $5.00
DIVISION: EDUCATION
DEPARTMENT: HOME & FAMILY EDUCATION
GENERAL EDUCATION: This course does not fulfill a General Education requirement.
CATALOG DESCRIPTION: A basic how-to course designed to teach construction techniques for home decor sewing. Pillows, pillow shams, dust ruffles, bedspreads, table linens, and window treatments will be included. Students are required to furnish the fabric and thread for individual projects.
DESCRIPTION: A basic how-to course designed to teach construction techniques for home decor sewing. Pillows, pillow shams, dust ruffles, bedspreads, table linens, and window treatments will be included. Students are required to furnish the fabric and thread for individual projects. Lab Fee: $5
TOPICS: Pillows; pillow shams; dust ruffles; bedspreads; table linens; shower curtains; window treatments including draperies, curtains, shades, blinds and valances
OBJECTIVES: The student will be able to:
1. Identify different fabrics and supplies used in home decor sewing.
2. Use appropriate sewing techniques.
3. Operate a serger, blind hem machine, sewing machine and other specialized equipment.
4. Measure, design and construct window treatments.
REQUIREMENTS: Projects;
Class presentation;
Web site evaluations;
Exams and quizzes;
Final exam
