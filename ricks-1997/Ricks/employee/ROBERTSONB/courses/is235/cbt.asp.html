Logging into the CBT System

Any user logging into the BYU-Idaho CBT courses must do so using his or her personal username and password. This is done using the online registration screen for the CBT server. The URL is http://cbt.byui.edu.

Registering to use the CBT Modules

Once you arrive at the CBT home page you will be prompted to register (figure 1). The first time in (and until the server is working properly, perhaps additional times as well) you will click the "Register" button, and then you will be asked to enter a user profile.

Figure 1

  1. The Username should be a unique code, numbers or letters, up to 8 characters. This will become your password into the CBT system.
  2. The Location should be BYU-Idaho.

The CBT course modules for the IS 235 course are:

  • Internet and Intranet Skills: Basic Concepts (CBT 1)
  • Advanced Web Authoring: Javascript: (CBT 2)

Accessing the Modules

To access the modules, you must click the Courseware button on the Smartforce page (figure 2). You will then be taken to a page listing all courseware by category. Click the button on the left-center portion of the page that says "Click here for list of available courses" (figure 3). You will then find youself on a page listing all courses. Our CBT courses are near the bottom of the page, so scroll down until you find the correct modules (figure 4). Click on the link for the desired module.

Submitting Test Results

After you complete a CBT module you will take the Course Exam. At the conclusion of the exam a results screen will be displayed. You have two options for submitting the results for the course. Everything will be posted to the web site, nothing will be turned in on paper.

One
When done with test, click Print
Change printer to Adobe Distiller, Print
Save file to web folder as cbttest#.pdf (# represents the module you are taking the test for)
Save a copy to Mars
Create a link from default to pdf file in your web site.

Two
Print to paper
Scan document and save as JPG file using a scanner
Save a copy to Mars
Create Link from default tothe JPG file in your web site.
