BYU-Idaho Computer Science Classes

The following listing of Computer Sciences classes provides the course number and title, number of credits, prerequisites, and course description for offered class. Not all classes are required for Computer Science majors. The course descriptions are followed by a summary of required classes for Computer Science majors.

CS 102 - Introduction to Computer Science (1)
Prerequisite: high school algebra
Provides information to help a student determine if he/she would like to major in Computer Science. Basic concepts of Computer Science, software engineering, and software development.

CS 104 - Ethics I (½)
Prerequisite: high school algebra
Survey of issues regarding ethics in Computer Science.

CS 124 - Introduction to Computer Systems (3)
How a computer works from hardware to high-level programming. Logic circuits, computer instructions, assembly language, binary arithmetic, high-level language, program translation, data structures, and algorithm analysis.

CS 144 - Introduction to Software Development (3)
Prerequisite: Math 110 (may be taken concurrently)
Algorithm formulation, problem solving, fundamental data types. Procedural paradigm of software development. Introduction to objects.

CS 148 - Computer Science Review (1)
Prerequisite: CS 165
Review of CS 165 concepts for those who have not been taking Computer Science classes for an extended period of time.

CS 165 - Object Oriented Software Development (3)
Prerequisite: CS 124, Math 110
Introduction to software design and development using an object oriented language. Introduction to software engineering principles.

CS 204 - Ethics II (½)
Prerequisite: CS 104
Overview of intellectual property rights relative to Computer Science.

CS 224 - Fundamentals of Digital Systems (3)
Prerequisite: CS 124
Digital logic: theory, design, and implementation of combinational and sequential logic. Laboratory experience in construction of digital logic circuits.

CS 235 - Data Structures (3)
Prerequisite: CS 165
Underlying programming concepts of recursion, sorting, stacks, queues, lists, binary trees, and graphs.

CS 236 - Discrete Mathematics for Computer Science I (3)
Prerequisite: CS 144 or CS 165, Math 112
First of a two semester sequence covering the mathematical foundations behind a variety of Computer Science topics. Projects will help explore the applications of discrete mathematics to Computer Science. Topics include logic, set theory, algorithmic analysis, number theory, proofs, recursion, combinatorics, and probability.

CS 237 - Discrete Mathematics for Computer Science II (3)
Prerequisite: CS 235, CS 236
Continuation of CS 236. Topics include relations and the relational data model, graph theory, trees, automata, languages and grammars, and Turing machines.

CS 273 - Web Engineering (3)
Prerequisite: CS 144 or CS 165
Internet and Web overview. Introduction to human-computer interaction. Information architectures. Client-server computing with client-side and server-side programming.

CS 304 - Ethics III (½)
Prerequisite: CS 204
Overview of privacy and confidentiality issues relative to Computer Science.

CS 324 - Computer Architecture (3)
Prerequisite: CS 224
Performance-directed design principles, advanced pipelining, instruction-level parallelism, compiler optimizations, and memory hierarchy design.

CS 330 - Programming Languages (3)
Prerequisite: CS 235
Major features of common programming languages; various types of languages including procedural, functional, and object-oriented; language translation including scanning and parsing techniques.

CS 345 - Operating Systems (3)
Prerequisite: CS 224, CS 235
Analysis and design of methods used by operating systems to perform typical system services; design and implementation of file and directory systems; I/O methods, including programmed, interrupt-driven, and DMA; CPU scheduling; memory management techniques and implementations; concurrent programming; deadlocks; protection mechanisms; distributed systems.

CS 346 - Software Design and Development (3)
Prerequisite: CS 235
Advanced object oriented design and software development.

CS 371 - Human-Computer Interaction (2)
Prerequisite: CS 273
Overview of human-computer interaction theories and methods. Graphical user interface design, user-centered design, usability engineering, user psychology, and the nature of human-computer interaction.

CS 404 - Ethics IV (½)
Prerequisite: CS 304
Overview of "harm to others" issues relative to Computer Science.

CS 426 - Software Engineering I (3)
Prerequisite: CS 346
Software requirements and design engineering.

CS 427 - Software Engineering II (3)
Prerequisite: CS 426
Software quality engineering and metrics.

CS 428 - Software Engineering III (3)
Prerequisite: CS 426
Software process management. Software project management.

CS 452 - Database Systems (3)
Prerequisite: CS 237
Study of database design and implementation; comparison of basic models (entity-relationship, hierarchical, network, relational); study of query languages; discussion of issues of integrity, security, dependencies, and normal forms.

CS 460 - Computer Communication and Networks (3)
Prerequisite: CS 345
Introduction to data communications and computer networking. Communications fundamentals, computer networks, software, architecture, telecommunications, regulations, standards.

CS 490 - Special Topics (3)
Prerequisite: consent of instructor
Current topics in Computer Science.

CS 498 - Internship (1-4)
Prerequisite: consent of department internship coordinator
Planned and supervised practical experience in vocational or educational settings. Interns acquire practical skills while applying classroom theory and principles.

CS 499 - Senior Project (3)
Prerequisite: CS 427, consent of instructor
Directed research and study of a topic in Computer Science not covered by the curriculum. The topic shall be such that the student shall apply material covered by the curriculum to understand a new topic.
