Excel Test Review

Can you:

  • Access or remove toolbars
  • Print preview and printing settings
  • Insert and naming or rename worksheets
  • use paste special to link objects
  • Use the edit and clear options
  • Use math operators (+, -, /, * , ^) in formulas
  • Use absolute, relative and mixed cell references in formulas
  • Name ranges
  • Move cells and ranges
  • Reference other worksheets and files
  • Sort
  • Calculate subtotals based on column labels
  • Create simple macros
  • Saving as HTML
  • Link to URL's or other files
  • Filter data
  • Create dynamic links
  • Use functions
  • Set cell or range formats (Numeric, text, date)
  • Use autoformatting
  • Set conditional formatting
  • Use line drawing and shading
  • Size columns and rows
  • Use Title Lock
  • Freeze and unfreeze frames
  • Create and modifying charts
  • Insert graphics

If you can, you will do very well on this test!
