Description An introductory course designed to teach basic aesthetic principles using the computer as a medium and 3D Studio Max software. The course will cover the creation of photo-realistic renderings and full-motion animations while applying correct use of lighting, shadows, color, composition, textures and materials. Topics include understanding a 3D work environment, object creation and modification, materials, lighting, cameras, rendering, and basic animation techniques.
Text Michael Peterson, 3D Studio Max 2 Fundamentals, New Riders, 1997
Materials 2-4 HD Floppy diskettes, 1 Zip disk (optional)

 

Course Objectives:

1. Introduce basic aesthetic design principles using the computer as the medium.

2. Be able to apply the correct use of lighting, color, composition, etc. in the generation of 3-dimensional computer rendering.

3. Demonstrate proficiency with the use of cutting-edge software in the creation of photo-realistic designs and full-motion animation.

4. Explain the differences that subtle changes in lighting, materials, etc. can have on the overall effect of a rendering.

5. Gain practical experience in computer design in a variety of disciplines including architectural design, mechanical design, product design, interior design, and landscape design.
