How to Find Music CD's

The main collection of Music CDs (compact laser discs) is located at the circulation area on first floor West Wing. You may search the collection by using the printed indexes located at the circulation desk or by using the Library Catalog. When using the Library Catalog, choose the General Search and limit the collection to Music CDs. In addition, be aware that the library has Reference CDs and Circulating CDs which may also be found by using the Library Catalog.
