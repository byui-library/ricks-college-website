General Instructions

  • All assignments except 00 shall be submitted by copying files to /home/twitchellk/cs148/hw##/, where ## is the two-digit homework number (be sure to include leading zeros when necessary). It is best to use submit148 to submit your homework. However, you may also use the Linux copy command (cp) to copy your files to the homework directory. Examples where whateverYouNamedIt is your file to be submitted and xyz99001 is your user ID):
    • submit148 whatever.cpp
    • cp whatever.cpp /home/twitchellk/cs148/hw##/xyz99001.cpp
  • All assignments shall be submitted as ASCII text files (i.e., submit the source code, not the executable).
  • C++ source code files shall be submitted using the .cpp extension.
  • Homework shall not be submitted using e-mail.
  • Make sure your submitted program satisfies all specified requirements.
  • Output shall exactly match the examples, with the only variation being output values that are calculated from input values.
  • All programs shall include error handling and shall terminate gracefully.
  • Whenever the homework specifies that the program is to loop until the user specifies to quit, the input from the user shall be the word "quit". Nothing more and nothing less.
  • For all character input, you must allow for the input of any case, including mixed case.
  • You may not use the system function in your programs.
  • Use C++ I/O (e.g., cout); do not use C I/O (e.g., printf).
  • Each program shall compile and execute using ROM 272 (Linux) lab computers.
  • Each line in each submitted file shall be less than 80 characters long.
  • Placing a portion of your source code in a header (.h) file is discouraged.
  • Homework is graded strictly on correctness of output. Be sure to thoroughly test your program before submitting it for grading.

02 Vending Machine
75 points
     Create a vending machine filled with items priced as specified in /home/twitchellk/examples/vm.txt. Assume that the customer has already successfully supplied $1 to the machine. Allow the customer to select a grid location (such as C5). Allow for both upper and lower case input (i.e. C5 and c5 are both valid).
     You may not use any selection or iteration structures. Assume valid user input. Process only one transaction. You do not need to output the vending machine grid. Deliver the correct amount of change using the least number quarters, dimes, and nickels.
     Example (user input is shown in bold): 
   Please enter a grid location (such as B2): C5
   Item C5 costs 60 cents.
   Change is 1 quarter(s), 1 dime(s), and 1 nickel(s).

04 Day of the Week
150 points
     Create a program to output the day of the week given a date. Prompt the user for a date composed of a numeric month, day, and year. Output the day of the week that date falls on.
     Continue to accept input until the user specifies to quit (by entering a single zero (0) -- nothing else). Provide specific instructions on how to quit the program.
     No date shall be earlier than Monday, January 1, 1753 (an earlier date is an error condition).
     Provide full error detection and handling.
     While the Unix cal utility may be used to assist algorithm design, it may not be used in the execution of the program. Use Zeller's Congruence or the C++ time function library.
     The program shall utilize functions. Use the main () function supplied in /home/twitchellk/examples/dayOfWeekMain.cpp. You may not modify the supplied main () function. Note that the names of some of your functions are dictated by the supplied main () function.
     Example (user input is shown in bold): 
   Enter date (MM/DD/YYYY) or 0 (zero) to quit: 2/29/2000
   2/29/2000 is a Tuesday
   Enter date (MM/DD/YYYY) or 0 (zero) to quit: 2/29/1900
   Input error: the day must range from 1 to 28
   Enter date (MM/DD/YYYY) or 0 (zero) to quit: 13/1/1999
   Input error: the month must range from 1 to 12
   Enter date (MM/DD/YYYY) or 0 (zero) to quit: 1/1/1752
   Input error: the year must be greater than 1752
   Enter date (MM/DD/YYYY) or 0 (zero) to quit: 0

06 Rational Number Calculator
125 points
     Create a class named Rational for performing arithmetic with fractions. Use integer variables for the numerator and denominator. Each instantiated object shall contain exactly one fraction. Provide public member functions for each of the following:
  1. Setting the value for a Rational number.
  2. Addition of two Rational numbers.
  3. Subtraction of two Rational numbers.
  4. Multiplication of two Rational numbers.
  5. Division of two Rational numbers.
  6. Displaying Rational numbers in the form i/j where i is the numerator and j is the denominator.
     Allow the user to enter an arithmetic expression (as shown in the examples below). Continue to accept input until the user specifies to quit (by entering a single zero (0) -- nothing else). Provide specific instructions on how to quit the program.
     Each operand shall be entered in the form of i/j, where i and j are integers (e.g., -11/52). Output the result as a (non-reduced) rational number.
     No friends. No operator overloading. The only valid operators are +, -, *, and /. Assume a complete arithmetic expression will be entered by the user. Assume that the first numerator will not be a zero (to avoid confusion with the quit command).
     Example (user input is shown in bold): 
   Enter an arithmetic expression using fractions or 0 to quit
   Input: 11/52+30/104
   2704/5408
   Input: 3/4*4/3
   12/12
   Input: 7/11+0/3
   21/33
   Input: 17/-5/-17/-5
   -85/85
   Input: 7/3-36/-12
   -192/-36
   Input: 1/2%3/4
   Input error
   Input: 1/0+9/7
   Error: cannot divide by zero
   Input: 5/8/0/3
   Error: cannot divide by zero
   Input: 0

10 Linked List
250 points

Input of a negative number results in the corresponding node being deleted from the linked list. An error message is output if there is no corresponding node. User entry of a zero terminates the program. The linked list is output after every non-zero user input.
     Use two classes: Node and LinkedList. The LinkedList class has insertNode and deleteNode member functions.
